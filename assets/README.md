# Қаріптер

`DejaVuSans-subset.ttf` және `DejaVuSans-Bold-subset.ttf` — DejaVu Sans
қаріптерінің латын + кириллица (қазақ әріптерімен) диапазонына қысқартылған
нұсқасы. PDF экспортына керек: pdf-lib-тің стандарт 14 қаріпі кириллицаны
мүлде білмейді, ал КП клиентке, деталировка цехқа кетеді.

Дереккөз: DejaVu Fonts (Bitstream Vera Fonts Copyright + Public domain қосымша),
еркін таралатын лицензия. https://dejavu-fonts.github.io/

Қысқарту `fontTools.subset` арқылы жасалды.
