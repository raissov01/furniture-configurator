# Проверка PRO100 — инструкция для тестера

Программа `pro100-bridge.exe` сама соберёт в вашем PRO100 несколько
тестовых шкафов, сохранит отчёты PRO100 и сравнит их с нашими расчётами.
Ваши проекты, настройки и библиотека PRO100 **не меняются**: мост создаёт
новый проект и сохраняет его только в свою папку с результатами.

## Что нужно

- Windows, установленный и активированный PRO100 v7.08.
- Два файла в одной папке (например, на Рабочем столе):
  `pro100-bridge.exe` и `pro100-test-kit.json`.

## Шаги

1. **Запустите PRO100.** Если открыт ваш проект — сохраните его (Ctrl+S).
   Окно PRO100 лучше развернуть на весь экран.
2. Откройте папку с файлами, в адресной строке папки наберите `cmd` и нажмите Enter.
3. В чёрном окне введите и нажмите Enter:

   ```
   pro100-bridge.exe audit pro100-test-kit.json
   ```

4. **Не трогайте мышь и клавиатуру примерно 15–20 минут**, пока в чёрном
   окне не появится надпись «Готово». Мост сам открывает окна PRO100,
   вводит размеры и сохраняет отчёты — это нормально.
5. Рядом появится папка `pro100-audit-<дата-время>`. Пришлите нам из неё
   файл **`pro100-audit.json`** (если не трудно — всю папку в архиве, там
   есть снимки экрана `shots`).

## Если что-то пошло не так

- Появилось окно лицензии/активации/регистрации PRO100 — мост **остановится
  сам** и ничего в нём не нажмёт. Закройте окно, как обычно, и запустите шаг 3 снова.
- Мост написал «открыт ваш несохранённый проект» — сохраните проект в
  PRO100 и запустите шаг 3 снова.
- Вы случайно тронули мышь и мост остановился («фокус ушёл из PRO100») —
  просто запустите шаг 3 снова.
- Компьютер медленный и мост «не дождался» окна — запустите так:
  `pro100-bridge.exe audit pro100-test-kit.json --slow 2`
- В любом случае пришлите `pro100-audit.json` — даже неполный прогон нам полезен.

## Перенос старого проекта (по желанию)

Откройте в PRO100 свой старый проект и выполните:

```
pro100-bridge.exe export-project
```

Мост прочитает структуру и отчёты (проект не изменится) и создаст папку
`pro100-project-<дата-время>` с файлом `pro100-project.json` — пришлите его нам.
