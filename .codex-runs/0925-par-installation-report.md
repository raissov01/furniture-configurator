# Монтажник өзегі және сервері — 2026-09-25

Бұтақ: `codex/0925-par`. Негізгі ағашқа, `codex/0924` және `main` бұтақтарына өзгеріс енгізілген жоқ. UI, браузер, e2e, dev server және build қолданылмады.

## Іске асқан келісім

- `src/core/installation.ts`: бес пункттік чек-лист; әр белгіленген пунктке фото дерегі керек. Клиенттің экрандағы қолы PNG сурет дерегі ретінде сақталады. Жабу тек барлық пункт пен фото, қол және аяқталған ремонт тапсырмаларынан кейін өтеді.
- Ақау нақты `panelId` арқылы жоба панеліне байланысады. Әр ақау жеке ремонт тапсырмасын ашады; ауыстырылатын детальға `encodePartQr` арқылы жаңа жапсырма QR-ы (нұсқа 2, 3, …) беріледі.
- Жабылғанда `finalPaymentLinkRequested` outbox оқиғасы бір рет жазылады. Төлем провайдері мен нақты URL генераторы әлі қосылмаған; оқиға сол интеграцияның кірісі болады.
- Сервер: `GET /api/installation` қысқа тізім, `GET /api/installation/:id` толық акт, `POST /api/installation/sync` офлайн кезектегі `SyncAction`. `shop` пен `owner` ғана рұқсат алады; дерек cookie аккаунтының `shopId` мәнімен оқшауланады.
- Әрекет ID-і қайталанса өзгеріс қайта жүрмейді. Нұсқа қайшылығы `409` және `{ kind: 'conflict', revision, serverValue }` қайтарады. Тапсырма, әрекет журналы және төлем оқиғасы бір SQLite транзакциясында жазылады. `4xx` қате кіріс/рөл/жоба үшін, `500` серверлік бүлінген дерек үшін; стек клиентке берілмейді.

## Офлайн/онлайн күйі

| Қызмет | Офлайн | Желі келгенде |
|---|---|---|
| Чек-лист, фото, қол дерегі | Клиентте сақтауға және `SyncAction` кезегіне қоюға болады | Сервер нұсқа мен деректі тексереді |
| Ақау, ремонт, QR есептеуі | Өзекте жергілікті есептеледі | Сервер панель ID-ін жобамен салыстырып бекітеді |
| Монтажды жабу | Әрекет кезекке түседі | Ресми жабу және outbox оқиғасы серверде жасалады |
| Соңғы төлем сілтемесі | Жоқ | Outbox тұтынушысы төлем провайдеріне қосылғанда жасалады |

UI кейін: фото түсіру, қол салу, чек-лист беті, ремонт ағыны және outbox тұтынушысы негізгі Codex-ке қалдырылды.

## Тексеру

- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run tests/installation.test.ts tests/installationRoute.test.ts --maxWorkers=2`: 6 тест өтті.
- `npm run -s typecheck`: өтті.
