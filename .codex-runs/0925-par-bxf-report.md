# BXF экспорт өзегі: зерттеу нәтижесі

**Күйі:** тоқтатылды. `src/core/export/bxf.ts`, fixture, тест және `docs/export/bxf.md` жасалмады.

## Негіз

- [Blum FAQ](https://www.blum.com/gb/en/services/faq/) BXF-ті XML негізіндегі proprietary формат деп атайды. Интерфейсті іске асырудың егжей-тегжейлі нұсқауы Blum-ның жеке байланыс адамы арқылы беріледі (2026-09-25 тексерілді).
- [Blum PRO100 беті](https://www.blum.com/gb/en/services/industrial-production/cad-cam-interface/software-partners/pro100/) импортталатын жоспарлау нәтижелері ішінде фурнитура, өндірістік дерек және ағаш бөлшектер барын растайды. Бұл бет XML элементтері мен атрибуттарын, нұсқа ережелерін немесе экспорт схемасын бермейді (2026-09-25 тексерілді).
- Берілген зерттеу (`~/furniture-configurator/.codex-runs/lite/bxf/bxf.md`) мен қорытынды (`~/furniture-configurator/.codex-runs/lite/bxf/REPORT.md`) ресми XSD, өріс сөздігі, өлшем және координат маппингі, фасад пен присадка XML құрылымы, лицензияланған fixture және коммерциялық қолдану шарттары табылмағанын тіркейді. Бұл екі кіріс файлы негізгі ағашта Git-тен тыс сақталған. Үшінші тарап жариялаған жекелеген тегтер толық схема орнына жүрмейді.

Сондықтан корпус, панель, фасад, Blum фурнитурасы және присадканы жарамды BXF XML-ге түрлендіретін функцияны не схемаға сәйкес fixture-ді сенімді жазу мүмкін емес. Ойдан XML құрастыру өндірістік деректі қате түсіндіру қаупін тудырады. Кері инженерия жасалмады.

## Іске асыруға қажет дерек

Blum-нан немесе уәкілетті серіктестен нақты BXF/BXF2 нұсқасына арналған implementation guide және XSD, қолдану/тарату шарттары, лицензияланған экспорт мысалы мен сәйкестік сынағы қажет. Оларда панельдің дайын және кесу өлшемдері, кромка, фасад, Blum артикулы, бұрғылау беті мен координат жүйесі анықталуы керек.

**Өзгеріс ауқымы:** тек осы есеп. UI, экспорт өзегі және e2e өзгермеді.

## Тексеру

- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run tests/export.test.ts --maxWorkers=2` — 20 тест өтті.
- `npm run -s typecheck` — бұрыннан бар, осы есепке қатысы жоқ `tests/veneerPricing.test.ts:39` қатесімен аяқталды: `number | undefined` аргументі `number` параметріне берілген. Бұл файл осы кезекте өзгертілмеді.
