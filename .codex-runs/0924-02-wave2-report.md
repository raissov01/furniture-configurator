## Ашық қалғаны

- ❌ Негізгі e2e толық жасыл емес: 8-сценарий бұрыштық шкафтың боковинасын 2 деп күтеді, кестеде 3 жол; 12–13 суық `/view` жүктелгенге дейін DOM-ды оқиды. Бұлар алдыңғы 1-толқын есебінде де бар. 8-сценарий бұрын үш талпыныстан кейін сенімсіз қалғандықтан, өндіріс ережесін болжап өзгертпедім. Келесі кезекте бір корпус scope-і мен көп корпус деталировкасын fixture-пен ажыратып, `/view` үшін DOM readiness күтуін дәлелдеу керек.
- ⚠ Viewer-де жолдық жеңілдіктер болса нақты соңғы сома орнына «Цена по запросу» көрсетіледі; құпия шығынсыз серверлік quote payload қажет. Vercel share/API 503 күйінде: тұрақты ортақ сақтау мен атомикалық rate limit backend керек. VPS SQLite және nginx ұсынымы дайын.
- ⚠ CLI-ге shop hardware каталогын беру жолы жоқ, сондықтан UI/CLI толық присадка паритеті тек project settings деңгейінде дәлелденді. Еркін тақтаға автоматты joint detection спек бойынша кейінгі фаза.
- ⚠ Еркін тақта кіретін «Замена» толық бағалық preview жасамайды; қате соманы көрсетпеу үшін UI мұны ашық жазады. Сыртқы normal карта жүктелмесе, желі қатесі PBR редакторында көрінбейді. AO/жарқыл PRO100 паритеті жоқ.
- ⚠ `claude/basis-script` екі белгілі ақау себебінен, `claude/catalog-materials` аяқталмаған үлкен WIP болғандықтан, `claude/pro100-bridge` осы толқыннан тыс және толық расталмағандықтан merge жасалған жоқ; себебі [ревью жазбасында](0924-basis-review-notes.md) және алдыңғы есептерде көрсетілген.
