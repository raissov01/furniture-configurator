# 0925-par — келісім мөрі және бирка QR өзегі

## Орындалды

- `src/core/approval.ts`: канондық JSON → SHA-256, бүтін тиын бағасы, өзгермейтін нұсқа снимогы, мақұлдау мөрі; өзгеріс болса жаңа нұсқа ашу.
- `app/api/share/[code]/approval/route.ts`: цех рөлімен ашу, бөлек 6 цифрлы кодпен клиент растауы, SQLite-де нұсқа тарихы, share өзгерсе 409, қате кодты шектеу, 4xx/500 қауіпсіз жауаптары. GET мөр дерегін немесе PDF-ті береді.
- `src/core/export/approvalPdf.ts`: хэш, баға, UTC уақыт, код және берілген болса 3D PNG бар PDF.
- `src/core/export/labels.ts`: `F1.` QR payload кодтау/декодтау (жоба, деталь, нұсқа), әр деталь биркасына вектор QR.
- `docs/approval-qr.md`: API келісімі мен ықпалдастыру шектері.
- Жаңа `qrcode-generator` тәуелділігі офлайн QR матрицасын шығару үшін керек; сурет немесе желі сервисі қажет емес.

## Тексеру

- Алдымен сәтсіз сынақтар жазылды: жоқ `approval.ts` және QR функциялары, жоқ API маршруты. Кейін іске асыру қосылды.
- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run tests/approvalRoute.test.ts tests/approval.test.ts tests/labels.test.ts --maxWorkers=2`: 24 тест өтті.
- Бұрынғы share рөлдері, КП экспорты және v4 миграциясы қосылған алты файлдық жүгіріс: 57 тест өтті.
- `npm run -s typecheck`: өтті.
- Мутация: SHA-256 кірісін тұрақты жолға ауыстырғанда жоба өзгерісі тесті құлады; `cp` арқылы қалпына келді.
- Мутация: QR-дегі нұсқаны әрдайым 1 еткенде roundtrip тесті құлады; `cp` арқылы қалпына келді.

## Функциялар күйі

| Функция | Күй |
| --- | --- |
| Жоба хэші, нұсқа моделі, QR кодтау/оқу, бирка/PDF құру | Офлайн |
| Растауды серверге жіберу | Онлайн; офлайн клиент кезегіне қоюды UI қосады |
| Share-ге байланған мақұлдау API және PDF алу | Онлайн |
| Кодты клиент телефонына жеткізу | Сыртқы SMS/WhatsApp арнасы қажет |

## UI кейін / белгілі шек

- Клиенттің «Мақұлдаймын» экраны, кодты бөлек арнамен жіберу, 3D кадрын PNG ретінде беру және сканер экраны осы өзек тапсырмасына кірмейді.
- Телефон нөміріне иелік ету API ішінде тексерілмейді: хабарлама жіберуші интеграция керек. Код POST жауабында тек цехтың рұқсатты сеансына беріледі.
- Share 24 сағаттан кейін жабылады. Мөр жолдары SQLite-де қалады, бірақ ұзақ мерзімді тапсырыс мұрағатының API-і әзірге жоқ.
