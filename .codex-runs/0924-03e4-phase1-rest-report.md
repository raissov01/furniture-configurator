## Келесі кезекке

1. Workspace Import панеліне бұрыннан бар DXF тақта және OBJ/GLB өзек парсерлерінің UI-ын жалғау; нақты импортталған нысанды жоба ағашына енгізу.
2. PRO100-дың Mesh/Hide/Kray/Light жеке панель паритетін және қалған төрт жоқ функцияны өнім шегіне сай жеке шешу. Lathe органикалық деталь болғандықтан қолданыстағы спекке кірмейді.
3. Жалпы e2e-дегі төрт бұрыннан бар сәтсіз қадамды жеке зерттеу; №18 баға моделі бойынша `CLAUDE.md` §6 шектеуін сақтау.
4. Осы кезең басталғаннан кейін `codex/0925-par` және `codex/0927-ui` бұтақтарына түскен жаңа коммиттерді келесі кезеңнің басында жеке ревью, merge және толық тесттен өткізу. `claude/market-prices-2` және `claude/qdesign-gaps-core` осы кезеңде біріктірілмеді: олар тыйым салынған еңбек ақы/баға моделі шекарасына жанасады.

Пайдаланушыдан осы кезеңге қажет шешілмеген сұрақ жоқ. Push пен deploy жасалған жоқ.
