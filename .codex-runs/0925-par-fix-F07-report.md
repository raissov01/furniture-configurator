## UI — негізгі кезекке

1. **Көп құрылғылы секция.** Асүй шеберінен пеш+СВЧ бағанын жасап, сол секцияда сөрені/штанганы/толтыруды өзгерту. `components/Configurator.tsx:64,70-119,344-345` бірінші құрылғыны ғана сақтап, екіншісін және жеке `height` мәндерін жояды. `contents` элементтерін индекс не тұрақты ID бойынша өңдеп, өзге жолақтарды сол күйі қалдыру; бірнеше құрылғы мен биіктікті бөлек көрсету.
2. **Телефон.** 390×844 экранда «Біздің» режимнің секция өрістеріне scroll арқылы жету және классикалық режимде «Свойства» батырмасын басу. `components/Workspace.tsx:536,978,1055-1085` өлшем/қабат қатынасын түзету; canvas үстіндегі батырма pointer оқиғасын алатындай ету.
3. **Механизмдердің көрінісі.** Бес механизмді кезекпен таңдау: `components/Scene.tsx:797-809` бәріне бірдей мөлдір box береді. Түрге сай қарапайым пішін және атау белгісін қосу.
4. **Құрылғы паспорт өрістері.** `components/Configurator.tsx:344-345` тек түрін таңдатады. Артикул, нақты ұяның `H/W/D` өлшемдері мен өндіруші талап ететін саңылаулар үшін өрістер қажет; өзек валидациясы төмендегі жауаптарға сүйенуі керек.

## Өндірістік шешімге қажет сұрақтар

- Нақты пеш, СВЧ, ыдыс жуғыш, тоңазытқыш артикулдары үшін қандай **ұяның** `H/W/D` өлшемдерін, желдету және орнату саңылауларын сақтау керек? Паспорт берілмегенде өндірістік экспортты тоқтату керек пе?
- Мойка мен газ/электр плитаның нақты артикулдары, үстелтақтадағы ойма контуры, жиектен шегінісі және өңдеу талабы қандай? Ортақ үстелтақтадағы ойма қай панельге байланыстырылуы тиіс?
- Ені 400 мм модульдегі мойкаға, 450 мм модульдегі плитаға қай нақты артикул сәйкес келеді? Визуалдың 760/590 мм әдепкі ендерін өндірістік минимум ретінде пайдалануға болмайды.

Мутациядан кейін өзгертілген файлдар `cp` арқылы қалпына келтірілді. Соңғы нысаналы тесттер: fixture + kitchen + hardware + pricing — 71/71. `npm run -s typecheck` өтті. Толық тест жиыны бұл параллель кезектің жад шектеуіне сай іске қосылмады.
