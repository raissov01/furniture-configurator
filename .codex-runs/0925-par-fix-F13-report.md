## UI — негізгі кезекке

1. **Прогулкаға кіру.** Қайталау: `/configurator` ашып, 1500×1000 экранда «Классический» таңдаңыз, шаблон галереясын жабыңыз. `components/Workspace.tsx:762` батырмасы `.legacy-tools` ішінде, ал `app/globals.css:121` бұл топты ≥1024 px экранда жасырады. `lib/classicMenu.ts:143-155` ішіндегі «Вид» мәзірінде прогулка командасы жоқ. Классикалық көрінетін toolbar-ға немесе «Вид» мәзіріне `setWalk` командасын қосу керек.
2. **Сборка қадамы.** Сол классикалық режимде «Сборка» белгішесін басыңыз: `components/Workspace.tsx:531` тек `null ↔ 1` ауыстырады. `components/Workspace.tsx:784-797` ішіндегі 1…N жүгірткісі `.legacy-tools` ішінде және `app/globals.css:121` бойынша жасырын. Классикалық toolbar-да қадамды өзгерту басқаруын көрсету керек.
3. **Прогулкадағы `E`.** «Наш» режимінде прогулкаға кіріп, `E` басыңыз. `components/Scene.tsx:249-252` және `components/Workspace.tsx:389-419` екеуі де `keydown` тыңдап, ашылу күйін ауыстырады; `lib/hotkeys.ts:48` `E`-ні жалпы hotkey ретінде береді. Прогулка кезінде жалпы `E` өңдеушісін өткізіп жіберу немесе пернені бір жерде өңдеу және клавиатура регрессия тестін қосу керек.
4. **Прогулка проекциясы.** «Аксонометрия» → «Прогулка» таңдаңыз. `components/Workspace.tsx:762` тек `walk` күйін өзгертеді; `components/Scene.tsx:1493` ортографиялық камераны `projection === 'ortho'` кезінде сақтайды, `components/Scene.tsx:1627` сол камераға `WalkControls` қосады. Кіргенде перспективалық камераны пайдаланып, шыққанда бұрынғы проекцияны қалпына келтіру керек.
5. **«План» проекциясы.** «Перспектива» → «План», сосын «Аксонометрия» → «План» таңдаңыз. `components/Workspace.tsx:96` қойындыда `projection` жоқ, `components/Workspace.tsx:1047` оны тек берілгенде орнатады. `lib/classicMenu.ts:144` пресетті ғана береді, `components/Workspace.tsx:460` пресет командасы проекцияны өзгертпейді. «План» үшін орто проекциясын барлық кіру жолында бекіту керек.
6. **Силуэт бойының шегі.** «Наш» → «Вид» → «Человек для масштаба» арқылы бойға `0`, `−1`, `2300` немесе бос мән енгізіңіз. `components/Workspace.tsx:835-843` HTML `min/max` бергенімен, `Number('') === 0`, соңында тек `Number.isFinite` тексеріледі; `store/configurator.ts:1304` кез келген санды қабылдайды. `src/core/silhouette.ts:19-20` ішінде 1000…2200 шектері бұрыннан бар. Енгізуді және setter-ді бүтін сан мен осы аралыққа тексеріп, бос мәннен күйді өзгертпеу және рұқсат етілген аралықты көрсету керек. Store файлы осы кезектің рұқсат етілген аясынан тыс; пайдаланылмайтын жеке core валидатор қатені түзетпейді.

Өндіріс ережесіне қатысты сұрақ жоқ. Түзету коды болмағандықтан мутациялық тексеру қолданылмады.

- `npm run -s typecheck` — өтті.
