# 05-фаза: жеке кітапхана есебі

Негіз: `b056787` (`codex/0924`). Жұмыс бұтағы: `codex/0924-05-phase5-library`.

## Нәтиже

- ✅ `SceneNode` тақта/шкаф/топты v1 JSON кітапхана элементіне сақтау; материал мен кромканың сілтемелерін тексеру. Қоюда түйін және шкаф ID-лері жаңадан жасалады, материал каталогына импортталады, терең топқа қою жұмыс істейді. Өндірістік `Panel[]` әр қойған сайын ағаштан есептеледі.
- ✅ Жергілікті кітапхана, JSON экспорт/импорт, бүлінген дерек пен қайталанған ID-ді ашық қате ету.
- ✅ SQLite-дегі пайдаланушыға байланған кітапхана және GET/POST/DELETE API; басқа пайдаланушының элементін оқуға/өшіруге болмайды. Аккаунтқа сақтау сәтсіз болса, интерфейс жергілікті көшірме күйін ашық көрсетеді.
- ✅ Редактордың `TreeDock` ішіндегі «Библиотека»: категория, сүзгі, іздеу, түйін таңдау, өлшемнен салынған SVG нобай, қою/өшіру, JSON және бүкіл кітапхана материалын ауыстыру.
- ✅ «Замена» жобаның канондық ағашындағы шкаф пен еркін тақтаның материалын бірге ауыстырады; бір undo қадамы. Материал қолдануы `flattenTree` арқылы көрсетіледі.
- ⚠ Ескі бағалық алдын ала есеп шкафқа негізделген. Еркін тақта әсерленсе, өзгеретін тақталар саны бөлек көрсетіледі, ал жаңсақ соманың орнына соңғы баға ауыстырғаннан кейін қайта есептелетіні жазылады. Канондық ағашқа толық баға preview-і келесі кезекке қалды.
- ⚠ Cloud өшірілген құрастыруда аккаунт API 503 қайтарады; жергілікті кітапхана істейді. Аккаунт кітапханасы қолданыстағы SQLite сервері қосулы жерде істейді.

## Тексеру

- Бастапқы база: 170 тест файлы, 1837 тест жасыл; `typecheck` жасыл (оркестрдің базалық жүгірісі).
- RED→GREEN: терең топқа қою; импорттағы жетіспейтін материал сілтемесі. Бағытталған кітапхана/API/store тесттері: 4 файл, 16 тест.
- Мутация 1: терең топқа жететін рекурсияны шектедім → `tests/library.test.ts` ішіндегі тиісті тест құлады; `cp` арқылы қайтардым.
- Мутация 2: жергілікті импорттың материал сілтемесін тексеруін өшірдім → `tests/libraryStorage.test.ts` тиісті тесті құлады; `cp` арқылы қайтардым.
- Бүкіл жиынтықтың бірінші жүгірісінде 175 файлдың 174-і, 1862 тесттің 1861-і өтті; жаңа сөздік кілттері EN/UZ тілдерінде жетіспеді. Үш сөздіктің кілтін теңестіріп, бағытталған тест пен typecheck жасыл болды.
- Соңғы толық test/typecheck: **175/175 файл, 1862/1862 тест және TypeScript қатесіз**.
- `node --check scripts/e2e.mjs` және `git diff --check`: жасыл.
- UI e2e сценарийі файлға қосылды: жергілікті сақтау → категория/іздеу → қою → өндірістік панель саны → қайта ашу. Бұл бұтақта build/dev/e2e іске қосылмады; интеграциядан кейін оркестр жүргізеді.
