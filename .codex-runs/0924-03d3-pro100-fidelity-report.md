## Келесі кезекке

1. Классикалық `Scene`: ақ торлы бөлме, текстурасыз әдепкі көрініс,
   таңдалған объектінің көк бояуы және бұрыш маркерлері. «Реалистичный»
   көрініс `Вид` мәзірінен қосылсын.
2. Properties General: Name тізімі → Width/Height/Depth және жеке
   құлыптар/пропорция → Show dimensions → Left/Bottom/Back реті;
   өндірістік өрістер Production ішінде қалсын.
3. Қалған классикалық диалог/панельдер, fieldset/button/tooltip/scrollbar
   пиксельдері; барлық бірдей аймақтың ΔE00 < 3 дәлелі мен кеңірек
   классикалық түстер линтері.
4. Негізгі e2e аккаунт ақауы: тіркелгеннен кейін `/api/projects` 401 қайтаруы
   `codex/0924`-те де қайталанды; бұл UI жұмысының сыртындағы ортақ мәселе.
