## Тексеру

- Өзгерген өзек пен MCP/бэкап жолдары: 13 файл, **279 тест өтті, 1 PostgreSQL интеграциялық тесті орта айнымалылары жоқ болғандықтан skip**.
- `npm run -s typecheck` өтті.
- Әр код түзетуіне тест алдымен қызыл болып, түзетуден кейін жасыл болды. Мутацияда бастапқы файл `cp` арқылы қайтарылды; тиісті тест қайта қызыл болды.

## Негізгі Codex/UI кезегіне

- `components/ShopSettings.tsx` ішіндегі `min={0}` мәнін `1` етіп өзгерту керек. `store/configurator.ts` ішіндегі `hydrateShop` parse қатесін әлі үнсіз жұтады; оны пайдаланушыға көрсетіп, жергілікті деректі әдепкі профильмен қайта жазуға жол бермеу керек. Бұл UI/store файлдары осы параллель кезектің рұқсат етілген ауқымынан тыс.
- Қашықтағы MCP үшін OAuth 2.1 authorization server, resource metadata, discovery, PKCE, клиент тіркеуі, токен audience/scope және цехқа байлау керек. Қазіргі bearer веб-сессия токенін remote connector-ға беруге болмайды.
- Қалған P2 мәселелері (`0695e53`, `ed9de23`, `4ed2b4e` және ревьюде аталған басқа тармақтар) бұл кезекте өзгертілмеді.
