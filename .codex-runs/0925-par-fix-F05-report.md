## UI — негізгі кезекке

1. «Фасадов → 9» немесе `8`, не «правый зазор → 51» енгізіңіз. `components/Configurator.tsx:355–367` және `components/ui.tsx:59–70` мәнді бірден жазады. `lib/usePanels.ts:28–49` пен `components/Workspace.tsx:313` 3D/деталировка күйін бірдей түсіндіруі керек: жарамсыз мәнді commit алдында тоқтату немесе екі көріністе де соңғы дұрыс жиынды анық белгілеу. Экспортты қате конфигпен ашпау қорғанысын сақтаңыз.
2. «Тип фасада → Вкладной», «Петля» тізімін ашыңыз. `components/Configurator.tsx:531–533,660–665` барлық seed жүйесін көрсетеді, әдепкі overlay болып қалады. Тізімді `fronts.mount` бойынша сүзу, сәйкес жүйе жоқ болса оны айқын көрсету және цех каталогына артикул енгізу жолын ұсыну керек. Core қазір қате жүйемен өндірісті тоқтатады.
3. «Фасадов → 3» немесе екі есікке «Все вправо/Все влево» қойыңыз. Core `sections[i].fronts.opening` қатесін береді. `components/Configurator.tsx:355–367,570–580` тірексіз комбинацияларды алдын ала түсіндірсін немесе таңдатпасын; секция бөлуге сілтеме пайдалы.
4. «Фасадов → 0» етіп, `‹` басыңыз. `components/ui.tsx:80–92` шекте батырманы `disabled` етіп, қолжетімділік күйін берсін; `›` үшін де max шегін қолданыңыз.

## Сұрақтар

- Inset фасад пен сөре арасындағы өндірістік монтаж саңылауы неше мм? Қазір тек нақты көлем қиылысы бұғатталады, ал саңылау тұрақтысы ойдан жасалмады.
- Цех қолданатын inset петлялардың артикулы және ресми чашка/планка присадка сызбасы қандай? Seed каталогына сенімді дерекпен ғана қосуға болады.
