## P2 — орындалғаны

- Lease мерзімі біткен job үш әрекеттен соң `failed`; келесі claim-де `attempts < 3` шарты бар (`3875498`).
- §4.7 бойынша 1–4 бірдей фасад саңылауының қалдығы алдымен сыртқы, кейін ішкі саңылауға берілетіні тексеріледі (`b08b8bf`).
- `cutPageTree` және `dockProduction` жарамсыз файлды тікелей `loadProject` арқылы ашады (`8b5ae8a`).

## Тексеру және шектеулер

- Әр P1 ақауына алдымен қызыл регрессия тесті жүргізілді; түзетуден кейін жасыл болды. `cp` сақтық көшірмесімен ескі әрекетті уақытша қайтарып, тесттің қайта құлағаны тексерілді. P2 job және фасад тесттеріне де мутациялық тексеру жасалды.
- Тек рұқсат етілген `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run <файлдар> --maxWorkers=2` және `npm run -s typecheck` қолданылды. Соңғы нысаналы топтамада P1 тесттері, P2-нің 36 тесті және typecheck өтті.
- Тірі PostgreSQL интеграция тесттері `DATABASE_URL` болмағандықтан skipped; PG worker өмір циклі fake `pg` клиентімен тексерілді. Толық `npm test`, build және e2e жүргізілген жоқ — осы кезектің жад/сервер шектеуі.
- Объект қоймасының цехтық квотасы орындалмады. Ол үшін сақтау транзакциясы, объект метадерегі және S3/диск өшіру кезіндегі есеп сәйкестігі қажет.
- F05 бойынша `CLAUDE.md` inset есікті талап етеді, бірақ әдепкі каталогтағы бекітілген inset петля артикулы жоқ. Сұрақ: нақты қандай inset петля мен монтаж өлшемін әдепкі цехқа бекітеміз және сәйкесі жоқта генерацияны қатемен тоқтатамыз ба? Өндірістік дерек расталғанша бұл ережені жорамалмен өзгертпедім.
