## Тест және мутация дәлелі

- Бастапқы `npm test -- --maxWorkers=3`: 419 файл/3026 тест жасыл; соңғы қолдағы толық жүгіріс: 504 файл/3346 тест жасыл. Тиісті typecheck жасыл. UI біріктіруінің бірінші толық жүгірісі 3 статикалық UI тесттен құлады; CSS пен мобильді тордың қайшы/ескі күтулерін нақты күйге келтіргеннен кейін толық жиынтық жасыл.
- Әдейі `600px → 601px` Properties биіктігі мутациясы 2 тестті құлатты; мобильді `max-content_max-content → minmax(0,1fr)_30dvh` мутациясы 1 тестті құлатты. Файлдар `cp` арқылы қалпына келтірілді. Бұрынғы брендті ілгек/кітапхана/құлыпталған қабат/қол баға тесттерінің мутациялары да red болды. Тәуелсіз аудиттің 5 мутациясы бөлек WIP тармағында қалды.
- `node --check` көшірілген e2e скриптіне жасыл. Properties/dock/annotations/property-scale және төрт мақсатты негізгі сценарий өтті. Бұрыштық сценарийдің үш CDP timeout-ы негізгі толық жүгірісті аяқтатпады; dev-сервер мен өз Chrome процестері тоқтатылып, 3141/9333/9334/9457 порттары бос екені тексерілді. - Тәуелсіз сервер аудиті WIP түзетулерін жаңа render маршрутымен біріктіріп, толық тест және typecheck жасыл болғанда бөлек merge; render job қайталағанда бір реттік quota reservation, upload body алдын ала шектеуі және per-account objectStorage quota.

- 03i cut/filter/label/lesson/folder/decor e2e, F01–F33 есептерінің браузер қадамдары, PG/SQLite compose e2e, `/api/v1` желілік smoke. Бұлт папкалары қазір осы браузердің localStorage-ында ғана.
- Бұрыштық корпусқа ауысқаннан кейін браузер renderer/CDP жауапсыз қалуының түбірлік себебін табу.
