## Тексеру

- TDD: әр пункттің жаңа таза функция сынағы алдымен қызыл болды, кейін жасыл болды. Әр пунктте `cp` арқылы қайтарылатын мутациялық тексеру тесті қатені ұстады.
- Жиынтық рұқсат етілген Vitest: **8 файл, 36 тест өтті** (`NODE_OPTIONS=--max-old-space-size=2048 npx vitest run ... --maxWorkers=2`). `npm run -s typecheck` өтті.
- Dev-сервер, `next build`, браузер және e2e жүргізілмеді.
- Бар `tests/cutPageTree.test.ts` файлын бөлек жүргізгенде бұрынғы invalid-board fixture `loadProject()` кезінде `parseProjectV4 → validateManualBoardDrilling` ішінде лақтырып, 1 тест құлады; жаңа сүзгі коды шақырылмайды. Бұл fixture/validation сәйкессіздігін негізгі кезекте бөлек тексеру керек.

## Шектеулер

- Папка мен сұрыптау метадерегі рұқсат етілген файлдар шекарасында аккаунт ID-і бойынша **осы браузердің localStorage** ішінде сақталады. Бір браузердегі бірнеше сеансқа жетеді; басқа құрылғымен бұлт синхрондалмайды. Ол үшін server/API migration бөлек жұмыс қажет.
- Декордың формасы қазіргі сахнаның `SolidNode` қорап сызғышына сай; сыртқы asset қолданылған жоқ. Басқа 3D mesh жасау үшін `Scene.tsx` керек болар еді, ол бұл кезектің рұқсат етілген UI тізімінде жоқ.
