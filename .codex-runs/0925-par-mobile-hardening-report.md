# 0925-par — телефон беріктендіру

## Атқарылғаны

- `claude/review-mobile` және `claude/fix-uz-dupes` `codex/0925-par` бұтағына біріктірілді; негізгі ағашқа тиіскен жоқпын.
- Телефон `navigator.storage.persist()` сұрайды, рұқсат нәтижесін көрсетеді; өлшем не кезек барда осы телефондағы дерек туралы ескертеді. Желісіз уақыт localStorage-да сақталып, 24 сағаттан соң еске салады.
- Service worker `/mobile` мен HTML-дегі статикалық ресурстарды орнату кезінде кэшке алады. Кэш нұсқасының ауысуы IndexedDB-ні жоймайды. Manifest бастапқы жолы `/mobile` болып қалды.
- Фото 2048 px ұзын жаққа дейін кішірейіп, JPEG 0.8 түрінде сақталады. Сығылған файл да 8 МБ-тан асса және сервер 413 қайтарса, түсінікті қате көрсетіледі.
- Бірдей өлшем екі қойындыдан жіберілгенде 409 сервер нұсқасының мазмұны дәл сәйкес болса, клиент оны қайшылық деп көрсетпейді. «Назад» черновик сақталмай қалса экраннан шықпайды. IndexedDB schema v2 жаңарғанда ескі қойынды байланысын жауып, экранды қайта ашады.
- Толық емес өлшемде «Сохранить замер» өшірулі. Ортақ Zod схемасы толық емес өлшемді серверге арналған `measurement.upsert` ретінде қабылдамайды (API тесті бастапқыда 200 қайтарды, түзетілгенде 400). Черновик IndexedDB-де сақталады. Ас үй қатары төрт қабырғаның кез келгеніне орналаса алады; қабырға мен бұрыш ауытқуының бүтін шектері экранда бапталады. Белгіленген кедергілер болса, модуль орнын кесуден бұрын қолмен тексеру ескертіледі.
- `publishShare` пен `whatsappLink` сервер кезегі жоқ болғандықтан online деп көрсетіледі. Телефондағы en/uz жолдары аударылды, үш сөздік кілті сәйкестендірілді.
- `/mobile/scan`: камерадағы QR (браузер BarcodeDetector қолдаса) немесе қолмен код, жоба интернеттен жүктелгеннен кейін оның кэштегі деталь өлшемі, кромкасы және присадка саны. `/mobile/installation`: актілердің жергілікті тізімі, бес пункттің фото дәлелі, клиенттің экрандағы қолы, ақау/жөндеу, жіберу кезегі. Бір актіде шешілмеген жіберу барда келесі әрекет бұғатталады; фото черновиктері IndexedDB-де қалады.
- `scripts/e2e-mobile-offline.mjs` енді 360/390/414 px, QR/монтаж бетін офлайн қайта ашу және `?v=` service worker жаңартқаннан кейін IndexedDB мен `/mobile` сақталуын тексереді. Сценарий **іске қосылған жоқ**: ортақ dev-сервер мен браузерге тыйым салынған.

## Тексеру

- TDD: service worker, online capability, ас үй қабырғасы, IndexedDB монтаж миграциясы және екі қойынды мазмұны тесттері алдымен құлады.
- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run` — нысаналы **15 файл, 84/84 тест** өтті (`--maxWorkers=2`).
- `npm run -s typecheck` — өтті.
- Мутациялар `cp` арқылы қайтарылды: mobile кэш жолын ауыстыру 1 тестті; фотоны 1024 px ету 1 тестті; қабырға шегін 1000 мм ету 2 тестті; аяқталған өлшем схемасын айналып өту API тестін құлатты.

## Негізгі Codex-ке қалғаны

1. **Келісім:** `components/ShareCodeDialog.tsx` пен классикалық конфигуратор баннері осы кезектегі өзгертуге тыйым салынған түбір компоненттер. 500 мс кейінге қалған share жіберулерін күту, WhatsApp-қа сервер мөрлеген бағаны беру және мақұлданған PDF-тің тұрақты сілтемесін көрсету аяқталмады.
2. **Галерея:** 390 px-тағы «С чего начнём?» терезесі `components/TemplateGallery.tsx` түбір компонентінде. Ол өзгертілмеді. `scripts/e2e-template-gallery.mjs` ішінде 360/390/414 px overflow және 390 px скриншот тексерісі бұрыннан бар; негізгі Codex іске қосып, қажет болса компонентті түзетеді.
3. **Браузер қабылдауы:** жаңа offline/QR/монтаж сценарийін нақты Chrome және iOS Safari құрылғысында негізгі Codex жүргізеді. Камера QR оқу браузердің `BarcodeDetector` қолдауына тәуелді; қолмен код енгізу әрқашан бар.

Push, deploy, dev-сервер, `next build`, браузер және e2e іске қосу жасалған жоқ.
