## Тексеру

- Бастапқы осы бұтақтағы алғашқы толық тексеріс: 174 файл / 1861 тест, typecheck жасыл.
- Соңғы тексеріс: `NODE_OPTIONS=--max-old-space-size=2048 npm test -- --maxWorkers=2` — **175 файл / 1864 тест**, бәрі жасыл; `NODE_OPTIONS=--max-old-space-size=2048 npm run typecheck` — жасыл.
- RED→GREEN: `boardProperties`, `boardStore`, `boardProductionUi`, `workspaceEmptyTree` тесттері. Бастапқы UI толық тексерісінде ескі board placeholder тесті құлады; ол нақты жаңа Properties мінезіне сай түзетілді.
- Мутациялар (`cp` арқылы сақтап/қайтару): материал қалыңдығының осін бұзу → core тест құлады; Properties-те `cutWidth` орнына `finishedWidth` шығару → production UI тесті құлады; `removeBoard` сүзгісін өшіру → store тесті құлады. Барлығы қалпына келтірілді.
