# 09-25 параллель жұмыс: парақ сметасы және шпон тобы

## Орындалғаны

- `codex/0925-par` worktree жаңартылды (`codex/0924`-пен біріктіру: өзгеріс жоқ). Негізгі ағашқа, `main`-ге және `codex/0924`-ке жазба жасалмады; push жоқ.
- `priceProject` бұрыннан раскройдың `byMaterial[].sheets.length` санын материал құнына қолданған. Бұл деректі `cutPlan` парақтарымен және смета жолымен салыстыратын тест қостым. Сыймаған деталь табылса, толық емес парақ санымен баға шығармайды.
- `Panel`/`BoardSpec`/v4 схемасына ерікті `veneerGroup` қосылды. Бір материалдағы бөлек топтар бір параққа араласпайды; топтағы детальдың декор бағыты сақталады. Топ `NestedSheet` нәтижесінде қалады.
- Спек: `docs/superpowers/specs/2026-09-25-veneer-matching.md`. Нақты суреттің үздіксіздігін, DXF таңбасын және UI баптауын кейінгі жұмыс ретінде шектейді. Ерікті полигон мен иілген пішіндердің өндірістік өлшемін ойдан шығармайды.

## Тексеру

- TDD қызыл күйі: жаңа тестте топтарды араластыру мен бағыт бұзу анықталды (3 сәтсіз, 1 өткен).
- Жасыл күйі: `tests/veneerPricing.test.ts` — 5/5 өтті; төрт мақсатты тест файлы бірге — 48/48 өтті.
- Мутация: `nesting.ts` ішіндегі топ оқшаулауы мен `pricing.ts` ішіндегі сыймаған деталь қорғанысы уақытша өшірілді. Жаңа тест 2 ақауды ұстады (2 сәтсіз, 3 өткен); екі файл `cp` көшірмесінен қайтарылды.
- Мутациядан кейін бастапқы файлдар көшірмемен бірдей екені SHA-256 арқылы расталды; 5/5 мақсатты тест қайта өтті. `git diff --check` өтті.
- `npm run -s typecheck` екі рет іске қосылды. Соңғысы 20 минут бойы CPU қолданып, еш қорытынды бермеді; ортақ жадқа түсетін салмақты шектеу үшін тоқтатылды. Тип тексеруі расталған жоқ. Тип қатесі туралы нәтиже шыққан жоқ.

## Кейін UI

- Шкаф фасадтарына және қолмен қойылған тақталарға топ атауын беру, раскрой парағындағы топты көрсету.
- DXF/PDF/CSV ілеспе дерегіне топ атауын енгізу. Қазіргі DXF геометриясы оны тасымалдамайды.
