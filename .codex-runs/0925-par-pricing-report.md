# 14-pricing: цех прайсын импорттау өзегі

Бұтақ: `codex/0925-par`, жұмыс ағашы: `.worktrees/par`. `codex/0924`-пен біріктіру тексерілді, жаңарту қажет болмады. Негізгі ағашқа өзгеріс жасалған жоқ.

## Жасалғаны

- CSV (UTF-8 немесе таңдалған Windows-1251) және XLSX бірінші парағын оқу; қате файлға өріс атаулы түсінікті хабар.
- Баған сәйкестендіру моделі: санат, артикул/декор коды, атау, бренд, қалыңдық, баға, бірлік және қосымша пішім/ен.
- Цех профиліндегі материал/кромка/фурнитураға каталог коды арқылы нақты, нормаланған, ұқсас сәйкестік; сенімділік көрсеткіші. Бірнеше нысана мен қайталанған баға қайшылық болып қалады. Ұқсас сәйкестік қолмен бекітілмей жазылмайды.
- Парақ, м², п.м., дана және теңге/тиын түрлендіруі; ақша бүтін тиын. Алдын ала көріністегі сәйкес/табылмаған/қайшылықты санағы. Таңдалған прайсқа жазу әрі snapshot синхрондау.
- Қолдану шарты: `docs/pricing-import.md`. Қосымша dependency жоқ: бұрыннан бар `fflate` пайдаланылды.

## Тексеру

- Тест алдымен жазылды: бастапқыда модуль жоқ болғандықтан қызыл.
- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run tests/priceImport.test.ts tests/priceLists.test.ts --maxWorkers=2`: 15 тест өтті.
- `npm run -s typecheck`: өтті.
- Мутациялық тексеру: м²-ден параққа айналдыру бөліміндегі бөлгішті әдейі өзгерттік; 2 тест қате ұстады. Файл `cp` арқылы қалпына келтірілді.

## Кейін

UI кейін: файл жүктеу, баған таңдау, алдын ала көрініс, ұқсас кодтарды бекіту және таңдалған прайсқа импортты шақыру. Бұл тапсырмада UI, браузер, e2e, build және dev-сервер қолданылмады. `CLAUDE.md §6` өзгертілмеді.
