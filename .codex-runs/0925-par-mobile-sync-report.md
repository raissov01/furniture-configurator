# 0925-par — телефонның офлайн синхрон өзегі

## Аяқталды

- `src/core/sync/`: тұрақты id бар әрекеттер журналы, `SyncStore` интерфейсі,
  `MemorySyncStore` фейкі, желі күйі, reconnect кезіндегі автоматты жіберу,
  1–60 секунд backoff және `nextRetryAt()`.
- Сервер қайшылығы revision нөмірі **немесе** уақыты өзгерсе анықталады.
  Жергілікті және сервер мазмұны қатар сақталады. `keepServer` және `keepLocal`
  таңдауы бар; екіншісі сервер revision-ына негізделген жаңа id шығарады.
- `OFFLINE_CAPABILITIES` — функциялардың ортақ офлайн/кезек/онлайн тізімі.
  UI `requiresInternet` арқылы екі тілдегі интернет белгісін қоса алады.
- `docs/offline-sync.md` — IndexedDB және сервер адаптерінің келісімі.

## Функциялар күйі

| Күй | Функциялар |
| --- | --- |
| Офлайн | өлшеу, фото/кедергі/ескертпе/дыбыс, генератор, ас үй шебері, 2D/3D, деталировка, раскрой, присадка, смета, PDF/DXF/CNC/CSV/XLSX/бирка, QR скан, жүктелген тапсырыс, цех белгісі, монтаж актісі, қолмен төлем жазбасы |
| Кезек | жоба/өлшем/фото/цех/монтаж/төлем синхроны, сілтеме жариялау, пікір/WhatsApp сілтемесі |
| Онлайн | бірінші кіру, команда/рөл, бұлттан жүктеу, клиент OTP бекітуі, банк төлемі, AI, дауысты тану, прайс жаңарту |

## Тексеру

- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run tests/syncQueue.test.ts tests/syncCapabilities.test.ts --maxWorkers=2`: 12 тест өтті.
- `npm run -s typecheck`: өтті.
- Мутация: backoff шегін 60 секундтан 1 секундқа ауыстырғанда тест құлады.
- Мутация: revision уақытын салыстыруды алып тастағанда қайшылық тесті құлады.
  Екі файл да `cp` арқылы қалпына келтірілді.

## UI кейін / интеграция шарты

- IndexedDB `SyncStore`, ірі фото/дыбыс object store-ы, reconnect және
  `nextRetryAt()` таймерін UI/браузер кезегі іске асырады.
- Сервер action id бойынша dedupe және base revision-мен шартты жазуды іске
  асыруы керек; онсыз клиент жалғыз өзі exactly-once кепілдігін бере алмайды.
- Желі жолағы, «Жіберілуді күтуде», қайшылық экраны және телефонның offline e2e
  қабылдау сынағы бұл параллель өзек тапсырмасының сыртында.
