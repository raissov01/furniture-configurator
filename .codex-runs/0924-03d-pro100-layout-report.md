# 03d — PRO100 десктоп жұмыс кеңістігі

## Нәтиже

- ✅ `docs/pro100/palette.md`-тегі нақты скриншот пиксельдері `--p100-*` CSS токендерімен бір орталыққа көшті. 3D сахнасының ақ фоны мен жылы тор түсі сол токендерден оқылады.
- ✅ Десктопта әдепкі «Классический» макет: кең орталық сахна, мәзір/құрал қатарлары, сол жақ тік құралдар, көрініс қойындылары, оң жақ төменгі Camera 1 және күй жолағы. «Наш» таңдауы браузерде сақталады; мобайлдағы бұрынғы орналасу сақталған.
- ✅ Панельді қос басу классикалық десктопта Properties модалін ашады. Нақты PRO100 v7.08 бойынша Lock · General (Name, H × W × D, Position) · Material · Reports + біздің Production; Show dimensions, OK/Cancel/Apply бар. «Наш» режимде және басқа 3D беттерінде есікті қос басу бұрынғыша ашады.
- ✅ Cancel/Escape жоба конфигін, undo/redo күйін және өлшем көрінуін бастапқы күйге қайтарады. Модаль ашық тұрғанда автосақтау/тарих/клиентке sync уақытша тоқтайды; Apply/OK жазады. Сақтау қатесі диалогта көрінеді, жабылмайды. Бос атау қате болып шығады.
- ✅ `scripts/e2e-pro100-properties.mjs`: 3D қос басу → Properties → енін өзгерту → OK → сақталған шкаф және деталировкадағы жаңа рез өлшемі. Синтаксис тексерілді; браузер сценарийін интеграцияда root орындайды.
- ✅ PRO100 эталон суреттері қаралды; `docs/pro100/ui-design.md` жаңартылды және `docs/pro100/layout-compare/README.md` айырмашылық кестесі жазылды. Эталон PNG репоға қосылған жоқ.
- ⚠ Өзіміздің Playwright скриншоты мен қатар визуалды салыстыруы интеграциядағы browser қадамында аяқталуы керек. Бұл worktree-де build/dev/browser іске қосылмады (жад шегі және root тапсырмасы).

## Қалған жұмыс және шектеу

- Интеграцияда `npm run build -- --webpack`, толық браузер e2e, PRO100 эталонымен біздің экранның Playwright скриншотын `docs/pro100/layout-compare/` ішінде салыстыру. Бұл қадамдарды root жад шегін сақтап кезекпен орындайды.
- Қалқымалы докинг және нақты PRO100 белгішелері тапсырма аясында жоқ. Camera 1 панелі бар пресеттерді басқарады; бөлек миниатюра рендер жоқ.
- Пайдаланушы шешетін сұрақ жоқ.
