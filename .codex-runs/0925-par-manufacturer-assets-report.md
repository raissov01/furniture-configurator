# 19-manufacturer-assets — өзек/дерек есебі

Күні: 2026-09-26. Бұтақ: `codex/0925-par` (`.worktrees/par`). `codex/0924` осы жұмыс алдында merge арқылы жаңартылды. Негізгі жұмыс ағашына өзгеріс жасалмады; push, dev-сервер, build, браузер, e2e қолданылмады.

## Нәтиже

- `src/core/manufacturerAssets.ts`: декор коды + құрылымы бойынша текстура дереккөзін шешетін модель. HTTPS сурет URL-і тек `licenseUrl`, `licenseId`, атрибуция және `saas-display` рұқсаты бар гранттан шығады. Қазір расталған гранттар жоқ; каталог ресми өндіруші бетіне сілтейді не `none` береді.
- `OwnMaterialMeta.textureSource`: әр материалда дереккөз мәртебесі сақталады. 1626 бастапқы декордан өрбіген каталог материалдары толық қамтылған; өндіруші суреттері/модельдері файл ретінде қосылған жоқ.
- `SolidSpec.modelSource` және v4 Zod схемасы: фурнитура моделінің сыртқы өндіруші беті немесе лицензияланған модель сілтемесі жоба файлы арқылы сақталады. UI кейін.
- `docs/assets/sources.md`: дайын зерттеу негізінде өндіруші шарттарының қысқаша кестесі мен қосу ережесі.

## Тексеру

- TDD: жаңа 4 тест алдымен құлады, іске асырудан кейін өтті.
- Мутация: `TextureGrantSchema`-дағы `saas-display` шартын уақытша бос мәтінге ауыстырғанда лицензия сынағы құлады (1/4). Файл `cp` арқылы қалпына келтірілді.
- `NODE_OPTIONS=--max-old-space-size=2048 npx vitest run tests/manufacturerAssets.test.ts tests/ownCatalogData.test.ts tests/ownCatalogSchema.test.ts tests/projectV4.test.ts --maxWorkers=2`: 4 файл, 63 тест өтті.
- `npm run -s typecheck`: өтті.

## Шектеу

Дайын зерттеуде өндіруші суреті не 3D моделін көп клиентті SaaS-та қайта таратуға айқын грант табылмады. Сондықтан нақты сурет/модель URL-і каталогқа енгізілген жоқ; ресми бет сілтемесі ғана бар. Грант қосу үшін өндірушінің жазбаша лицензиясы және оның идентификаторы қажет.
