## Қолдану ескертпесі

- `--p100-room-grid` бір сызықтың таза пикселі. Сол сызықтың айналасындағы
  антиалиас пиксельдері (`#FBF4F0`, `#FDF9F7` және басқалары) фонмен араласқан;
  оларды жеке дизайн токені ретінде алмау керек.
- Құрал батырмасының көк түсі мен диалог фокусы екі бөлек жүйелік күй:
  `#CCE8FF` пен `#0078D4` әртүрлі мақсатқа арналған.
- Терезе тақырыбының бояуы екі суретте әртүрлі, себебі Windows белсенділік
  күйі өзгерген. Оны қолданбаның тұрақты CSS палитрасына қоспаймыз.
- Бұл кесте түстерді өлшейді; скриншоттардағы белгішелер, логотип пен брендті
  қайталау үшін негіз емес.
