# PRO100-дың интерфейс құрылымы

**Күні:** 2026-09-20
**Мақсат:** PRO100-дың макетін негізге алып, үстіне өз функцияларымызды қосу
(пайдаланушының бастапқы идеясы)

Бастапқы макет `PRO100.layout` және жария сипаттамалардан талданды.
2026-09-24-те интерфейстің нақты v7.08 скриншоттары қаралып, Properties
қосымшалары соларға сай түзетілді. Дереккөздер:

1. `PRO100.layout` — бағдарламаның өз **XML докинг макеті** (архивтен);
2. PRO100-дың **жария сипаттамалары** мен оқулықтары (маркетингтік материал);
3. `dialog-properties-general.png`, `dialog-properties-material.png`,
   `dialog-properties-reports.png` — v7.08 интерфейсінің анықтамалық скриншоттары.

Көшірілетіні — **макет пен өзара әрекет үлгісі**, олар қорғалмайды.
Белгішелер, сурет, бренд көшірілмейді.

---

## 1. Терезенің өлшемі (`PRO100.layout`-тан)

```
Терезе:  1544 × 824
Scene:   1013 × 533   (орталық 3D көрінісі)
```

Яғни панельдерге көлденеңінен 531 px, тігінен 291 px қалады.

## 2. Докингке қойылатын 14 панель (`PRO100.layout`-тан)

```
Scene                 ← орталық 3D
Библиотека            ← элементтер мен материалдар қоймасы
Структура проекта     ← ағаш (бізде StructureTree болады)
Прайс-лист
Kray                  ← рендер қозғалтқышы
Mesh
Найти
Свет
Информация
Скрыть
Токарный станок       ← иілген/токарлық деталь
Текст
Замена                ← материалды жаппай ауыстыру
Слои
Размеры
```

Әдепкі макетте бәрі **қалқымалы** (`PlacementInfo.State = 0`, өлшемі 450×200),
тек `Scene` докталған. Яғни пайдаланушы панельдерді өзі қалаған жаққа қояды —
бұл PRO100-дың негізгі UX идеясы.

## 3. Бес құралдар қатары (жария сипаттамадан)

```
Стандартная · Вид · Набор инструментальных средств
Свойства · Передвинуть/Выровнять
```

Соңғысы маңызды: **придвижение · позиционирование · выравнивание · обороты**
— яғни привязка мен туралау бөлек қатарда тұрады.

## 4. ⚠ ЕҢ МАҢЫЗДЫ ИДЕЯ — бір Properties терезесі, үш қосымша

```
General · Material · Reports
```

Нысанды таңдап, **қос басасың** (не Properties ашасың) — сонда сол нысан
туралы негізгі мәлімет бір терезеде. PRO100 v7.08-дің нақты скриншотында
`General` қосымшасының ішінде **Name, Dimensions, Position** бөлімдері бірге;
`Material` екінші, `Reports` үшінші қосымша. `Reports` ішінде Price ID мен
бөлшек/материал есебінің параметрлері бар. Бөлек `Dimensions` не
`Calculation` қосымшасы жоқ.

Жария сипаттамадағы сөз:

> «почти все основные действия лежат в одном окне, и не надо отдельно искать
> параметры имени, размеров, материалов и цены в разных частях интерфейса»

## 5. Бізде қазір қалай (2026-09-25)

03-фазаға дейін оң жақта **ұзын жылжымалы панель**, ішінде көп `▶` бөлім болды:

```
ПОЛОЖЕНИЕ В КОМНАТЕ · КОНСТРУКЦИЯ · СКОС (МАНСАРДА)
УГЛОВОЙ (ПЕРЕХОДНОЙ) · ФРОНТАЛЬНАЯ ПАНЕЛЬ
ОСНОВАНИЕ И СТОЛЕШНИЦА · ПЛАНКИ И ФАРТУК · ДВЕРИ · МАТЕРИАЛЫ
```

Қазір шкаф пен еркін тақтаның оң жақтағы Properties панелі төрт қосымшалы:
PRO100-дағы **General
(аты, H × W × D, орны) · Material · Reports** және біздің **Production**.
Присадка Production ішінен бөлек модаль терезеде ашылады; раскрой — `/cut`.

## 6. Нақты айырмашылық

| | PRO100 | Бізде |
|---|---|---|
| Қасиеттер | **3 қосымша, бір терезе** | 3 эталон қосымша + Production, бір оң панель |
| Панельдер | 14, **қалқымалы, өзің қоясың** | бекітілген орындар |
| Кіру жолы | нысанды **қос басу** | оң панельге қарау |
| Туралау/привязка | **бөлек құралдар қатары** | StructurePanel ішінде X/Y/Z туралау, массив және тор/шек өрістері; еркін тақта 3D snap алады |
| Материалды ауыстыру | «Замена» панелі | TreeDock-та «Замена», канондық шкаф пен еркін тақтаға |
| Қабаттар | «Слои» панелі | TreeDock-та «Слои» |

## 7. Ұсынылатын жол

### Қадам 1 — Қасиеттерді үш эталон қосымшаға жинау ✅

Бұрынғы ~9 бөлім PRO100-дың үш қосымшасына және бөлек Production қосымшасына
жиналды. Өндіріс әрекеттері үшін төртінші қосымша — біздің жоба шешімі, PRO100
v7.08 құрылымына телінбейді.

| Қосымша | Не кіреді |
|---|---|
| **Жалпы** | аты, H × W × D, бөлмедегі орны, скос, бұрыштық, фронт. панель, негіз/столешница |
| **Материал** | корпус, фасад, кромка, фрезеровка, текстура бағыты |
| **Есептер** | баға, деталировка үзіндісі, фурнитура саны |
| **Өндіріс (біздікі)** | қол присадкасы, DXF/CSV/XLSX экспорты |

⚠ Бұл — **қайта топтастыру, қайта жазу емес.** Бар компоненттер сақталады,
тек орналасуы өзгереді.

### Қадам 2 — Қос басу қасиеттерді ашады

Қазір 3D-де есікті қос басу оны ашады/жабады; таңдалған шкаф не еркін тақтаның
Properties-і оң панельде көрсетіледі. PRO100-дағыдай қос басуды Properties-ке
бағыттау — кейінгі UX шешімі.

### Қадам 3 — Бізде бар, PRO100-да ЖОҚ функцияларды сол құрылымға қосу

Парити кестесі (`docs/pro100/parity.md`) бойынша бізде күштірек:

```
Присадка (PRO100-да МҮЛДЕ жоқ — ол Базиске тапсырады)
Гильотиндік раскрой верификаторы
ЧПУ экспорты, деталь бойынша
Кромка шегерімінің құжатталған ережелері
AI бриф → нақты корпус
AR / VR
Клиентке 6 таңбалы кодпен бөлісу
Прогулка
```

Олар **қосымша бөлім** болып қосылуы мүмкін («Өндіріс» не «Цех»), не
бөлек панель ретінде.

### Қадам 4 — Кейінге: қалқымалы панельдер

PRO100-дың докинг жүйесі (панельді қалаған жерге сүйреу) — үлкен жұмыс әрі
браузерде күмәнді. **Алдымен қадам 1–3, докингті кейін бағалаймыз.**

## 8. Не көшірілмейді

- Белгішелер мен сурет (Ecru-дың меншігі)
- Бренд, атау, түс схемасы
- Диалогтардың дәл пиксельдік орналасуы

Көшірілетіні — **функцияның құрылымы мен өзара әрекет үлгісі**.
