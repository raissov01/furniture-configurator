# Классикалық құрал белгішелерінің сәйкестігі

Эталон: жергілікті `base-inserted.png`, алғашқы 4 қатардағы белгішелер.
Біздің белгішелер `components/ClassicIcon.tsx` ішінде нөлден салынған 18 px
SVG; эталон суретінің пиксельдері көшірілген жоқ. Акцент түстері
`docs/pro100/palette.md`-тегі нақты пиксельдерден алынды.

| Эталон орны/зат | Біздің SVG | Мағынасы | Әрекет |
|---|---|---|---|
| 1-қатар, ақ парақ | `new` | Жаңа корпус | `addCabinet` |
| 1-қатар, сары қалта | `open` | Жобаны ашу | `ProjectMenu` файл өрісі |
| 1-қатар, көк дискета | `save` | Файлға сақтау | `ProjectMenu` сақтау әрекеті |
| 1-қатар, принтер | `print` | Смета | `setQuoteOpen` |
| 1-қатар, қайшы | `cut` | Раскрой | `/cut` беті |
| 1-қатар, қос парақ | `copy` | Дубликат | `duplicateCabinet` |
| 1-қатар, қызыл крест | `delete` | Өшіру | `removeCabinet` |
| 1-қатар, кері/алға жебе | `undo`, `redo` | Қайтару/қайталау | `undo`, `redo` |
| 1-қатар, тетік | `settings` | Цех баптауы | `setShopOpen` |
| 2-қатар, қорап | `box` | Тұтас көрініс | `setViewMode('solid')` |
| 2-қатар, сым қорап | `wire` | Сым көрініс | `setViewMode('wire')` |
| 2-қатар, көз | `eye` | Өлшем жазуы | `setShowDimensions` |
| 2-қатар, қызыл магнит | `magnet` | Привязка | `setSnapOptions` |
| 2-қатар, сары шам | `light` | Жарық/рендер | `setRenderOpen` |
| 2-қатар, сызғыш | `measure` | Өлшем жазуы | `setShowDimensions` |
| 2-қатар, төрт бұрыш жебесі | `fit` | Кадрға сыйдыру | `fitCamera` |
| 3-қатар, ағаш түйіндері | `structure` | Құрылым | қалқымалы `TreeDock` |
| 3-қатар, қатпарлар | `layers` | Қабаттар | қалқымалы `TreeDock` |
| 3-қатар, кітаптар | `library` | Кітапхана | қалқымалы `TreeDock` |
| 3-қатар, қос қорап | `duplicate` | Дубликат | `duplicateCabinet` |
| 3-қатар, айна | `mirror` | Айна көшірме | `mirrorCabinet` |
| 3-қатар, жиналған тақта | `assembly` | Жинау | `setAssemblyStep` |
| 3-қатар, тақта | `board` | Еркін тақта | `addBoard` |
| 3-қатар, бөлме | `room` | Бөлме баптауы | `setRoomOpen` |
| 4-қатар, монитор | `render` | Рендер | `setRenderOpen` |
| 4-қатар, парақ | `quote` | Смета | `setQuoteOpen` |
| 4-қатар, тесік | `drill` | Присадка | `setDrillOpen` |
| 4-қатар, сұрақ | `help` | Көмек | `setHelpOpen` |

Белгішелер бар функцияларға жалғанған. Сол жақ тік қатардағы көрініс,
тақта, сызғыш және құрылым сол SVG жиынтығын қайта қолданады.
