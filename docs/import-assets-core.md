# DXF және 3D модель метадерегі импортының өзегі

`src/core/import/dxfBoard.ts` ASCII DXF-тегі бір жабық, осьтерге параллель тікбұрышты кесу контурын `BoardNode`-қа айналдырады. `OUTLINE` қабаты болса, сол таңдалады; басқа жағдайда бір ғана контур қабаты немесе шақырушы берген `layer` қажет. `LINE`, `LWPOLYLINE`, `POLYLINE` қабылданады. Орналасу DXF-тегі ең кіші X/Z координатасына қойылады. `materialId`, түйін id-і мен аты шақырушыдан алынады. DXF-тегі өлшем кесу өлшемі болғандықтан импортта кромка бос болады: дайын өлшем мен рез өлшемі бірдей. Кромка кейін берілсе, рез өлшемі жобаның §4.3 ережесімен өзгереді.

Бөлме қабырғасы импортындағы ASCII DXF токенизаторы, секция/нысан оқығышы және `$INSUNITS` қайта санауы ортақ. Өндірістік импортта өлшем бірлігі міндетті. Доға, қиғаш немесе ашық контур, сондай-ақ `CUTOUT`, `GROOVE`, `MILLING` операциялары анық қатемен тоқтайды: қазіргі `BoardSpec` оларды толық қалпында сақтай алмайды. Басқа қабаттағы бұрғы шеңберлері контурға қосылмайды; тесіктер бөлек импортталмайды.

`src/core/import/solid.ts` OBJ мәтініндегі `v`/`usemtl` жолдарын немесе GLB 2.0 JSON chunk-індегі белсенді scene, mesh primitive, `POSITION` accessor min/max және материал атауларын оқиды. Нәтиже: `SolidNode` қорабы және `materialNames` тізімі. Габарит пен орын бүтін мм-ге дөңгелектенеді. OBJ бірлік сақтамайды, сондықтан `mmPerUnit` міндетті. GLB-тің әдепкі бірлігі метр, яғни 1000 мм; бұл [Khronos glTF 2.0 спецификациясына](https://github.com/KhronosGroup/glTF/blob/main/specification/2.0/Specification.adoc) сай. Түйіннің matrix/TRS түрлендірулері есепке алынады. Міндетті `POSITION.min/max` жоқ болса, файл қабылданбайды.

`SolidSpec` тек өлшем мен көрініс атрибуттарын сақтайды: OBJ/GLB mesh байттары, файл жолы және материал атаулары v4 жобаға жазылмайды. `solid` түйіні өндірістік панельге, раскройға не автоматты сметаға кірмейді. Болашақ UI бастапқы файлды бөлек сақтау мен 3D loader-ге беру тәсілін, сондай-ақ материал атауларын көрсетуін шешуі керек. Қазіргі функция тек геометриялық қорап пен метадерек береді.
