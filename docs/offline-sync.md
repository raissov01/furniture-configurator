# Телефонның офлайн синхроны: өзек келісімі

`src/core/sync/` — браузерге тәуелсіз TS модулі. Ол `SyncStore` арқылы журналды
сақтайды. `MemorySyncStore` — тестке арналған фейк; IndexedDB адаптерін UI
кезегінде жазу керек. Оның `insert` амалы `action.id` бойынша **атомдық** болуы
керек. Үлкен фото/дыбыс файлдары бөлек object store-да жатады; әрекет payload-ы
олардың жергілікті сілтемесін ұстайды.

Әр әрекетке клиент тұрақты кездейсоқ `id` береді. Retry кезінде `id` те, payload
та өзгермейді. Сервер осы `id` арқылы қайталанған сұрауды тануға және бұрынғы
жауабын қайтаруға міндетті. Сервер өзгерісті `baseRevision.version` және
`baseRevision.updatedAt` мәндері сәйкес келгенде ғана қабылдайды. Екеуінің
біреуі өзгеше болса, `conflict` + сервер нұсқасы/мазмұны қайтады. Уақыт
«соңғы жазған жеңеді» шешімі үшін қолданылмайды. Қайшылық журналда екі мазмұнмен
сақталады. `keepServer` жергілікті өзгерісті тоқтатады; `keepLocal` сервер
нұсқасына негізделген **жаңа id** бар әрекет шығарады. Шешім UI пайдаланушысынан
келуі тиіс.

`setOnline(true, now)` байланыс оралғанда жіберуді бастайды. `flush(now)` қолмен
«Бәрін жіберу» үшін және таймер үшін. Уақыт миллисекундтық бүтін Unix timestamp.
Уақытша қате 1, 2, 4 ... 60 секунд backoff алады; `nextRetryAt()` қай кезде
келесі `flush()` керегін береді. Браузер адаптері осы уақытқа таймер қояды және
терезе ашылғанда, желі оралғанда қайта flush жасайды. Жалғыз `navigator.onLine`
серверге жетуді дәлелдемейді: transport қатесі `unreachable` күйіне ауыстырады.

`OFFLINE_CAPABILITIES` — интернетке тәуелділіктің ортақ тізімі. `offline` жергілікті
жүреді; `queued` жергілікті тіркеліп, серверге кейін жіберіледі; `online` желісіз
басталмайды. UI «Интернет арқылы жұмыс істейді / Работает через интернет»
белгісін `requiresInternet` мәнінен және сұр күйін `mode` мәнінен шығара алады.
`queued` функцияның жергілікті жазбасын сақтау UI/IndexedDB жауапкершілігі.

Сервердің idempotency кілті, шартты revision жазуы, IndexedDB адаптері және
телефондағы offline e2e қабылдау сынағы осы өзек модулінен тыс интеграцияда
аяқталуы керек.
