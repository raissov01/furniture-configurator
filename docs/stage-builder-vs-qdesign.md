# Кезеңдік құрастырғыш: функция салыстыруы

Дерек: 2026-09-06 күнгі qdesign шеберінің функционал жазбасы (`project_furniture_configurator_generator.md`), 2026-09-20 визуал аудиті және осы репозиторий коды. Салыстыру функцияға қатысты; бәсекелестің мәтіні мен интерфейс суреті көшірілмеді.

| Функция | qdesign эталоны | AisMebel осы бұтақта |
|---|---|---|
| Бес қадам, артқа/алға | Бар | Бар; кез келген қадамға жолақтан өтуге болады. |
| Қабырға пішіні | Тура, Г, П | Ас үйде үшеуі; шкаф, комод және кабинетте тура/Г; ТВ мен жатын бөлмеде тура. |
| Жиһаз түрі | Төртеуі белсенді, кабинет/жатын бөлме «жақында» | Алтауы белсенді; кабинет — үстелдер, жатын бөлме — кереует пен тумбалар. |
| Қабырға бойынша модуль бөлу | Авто және саны | Авто бөлу бар; модуль санын жеке қолмен бекіту жоқ. |
| Ас үйдің өлшемдері | Төмен/жоғары қатар, цоколь, үстел беті, фартук | Өлшемдер бір драфттан генераторға өтеді; стандартты ендерге жақындату өзекте бар. |
| Раскладка | Қосу, алып тастау, жылжыту, техника | А/В қатарының модуль түрін, енін, ретін өзгерту бар; сызбадан сүйреу жоқ. |
| Конструкция | Тұтқа, топса, тартпа жүйесі, жарық | Цех профилі қолданылады; шеберде жеке артикул таңдауы жоқ. Жарық пен техника жалаушалары бар. |
| Материал | Корпус, фасад топтары, цоколь, үстел беті, фрезеровка | Корпус, фасад, үстел беті, фасад фрезеровкасы; әр фасад тобының материалы бөлек жоқ. |
| Әр қадамда 3D және баға | Бәсекелес шеберінің толық мүмкіндігі бұл жазбада расталмаған | Бір драфттың `Panel[]`-інен 3D қораптар және `priceProject` бағасы. Бағасы жоқ позициялар көрсетіледі. |
| Сөзбен енгізу | Бар | `/api/generate` арқылы бар; желісіз ЖИ сұрауы жұмыс істемейді. |
| Телефон өлшемі мен кедергілер | Салыстыру дерегінде жоқ | Телефон өлшеу ағыны жобада бар; осы шеберге кіріс ретінде жалғанбаған. |
| Сақталған жеке шаблон | Салыстыру дерегінде жоқ | Жеке кітапхана жобада бар; шебер нәтижесін бірден сонда сақтайтын батырма жоқ. |
| Деталировка мен смета | Генерациядан кейін бар | Генерациядан кейін ортақ `Panel[]`, раскрой және смета қолданылады. |

Өндірістік шекара: техникаға арналған нақты ойық, брендке тән присадка және тапсырыс беруші кедергісі нақты паспорттық өлшемсіз автоматты өндірістік деталь болып саналмайды. Бұлар шеберде толық жасалды деп белгіленбейді.
