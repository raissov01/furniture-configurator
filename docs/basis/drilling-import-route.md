# Присадканы Базиске жеткізу жолы — дереккөзбен (2026-09-24)

## Тұжырым
1. **Базис-Раскрой присадканы импорттамайды.** Ол тек ПАНЕЛЬ ТІЗІМІН MS Excel-ден (xls/xlsx)
   оқиды: бағандарды қолмен сәйкестендіру + «Длину и ширину считывать как готовую» опциясы
   (Модуль БАЗИС Раскрой, Руководство пользователя, 15.05.2026, §5.2.5). Сақтау: xls/xlsx, cutwork,
   oblx, csv (Табл. 5.2).
2. **Базис-Мебельщиктің импорт форматтарында CSV/присадка жоқ** (Руководство пользователя,
   29.04.2026, Табл. 6.2: VRML/X3D, md3, obj, bmp/jpg, bxf DYNAPLAN BLUM; бөлек — bCAD, K3, Hettich).
3. **Присадканың жалғыз құжатталған жолы — Базис JavaScript скрипт API-і** (ресми, MIT лицензиясы,
   https://github.com/BazisSoft/Scripts, типтер `node_modules/@types/bazis/index.d.ts`). Тесік Базисте
   жеке «тесік» емес, КРЕПЕЖ моделі ретінде 3D әлем координатасында қойылады:
   - `Mount1(panel, x, y, z, angle)` — панельдің пластіне крепеж;
   - `Mount(panel1, panel2, x, y, z)` — екі панель арасына;
   - `MountScheme(panel1, panel2, FurniturePosition, BasisPoint)` — стыкқа схема.
   Демек **«outer бетінің X/Y-ін айналдыру керек пе» деген сұрақ Базис үшін ЖОҚ**: координата әлемдік 3D.
4. qdesign.kz дәл осы жолмен жұмыс істейді: «Экспорт в Базис» = 6 таңбалы код + Базистің Scripts
   қалтасына салынатын `importQdesign.js` (скрипт жобаны серверден тартып, панель мен тесікті Базисте
   құрады). Скрипт обфускацияланған — ішін талдамадық/көшірмедік; тек жалпы тәсіл (функция деңгейі).

## Біздің экспортқа салдары
- `src/core/export/basis.ts`: `detali.csv` → Базис-Раскройдың Excel импортына сай (xlsx да болады;
  «готовый өлшем» ережесі дұрыс — Раскройдың «как готовую» опциясымен сәйкес).
- `prisadka.csv`: Базисте тұтынушысы ЖОҚ. Оны не алып тастау, не «Базиске емес, адамға/басқа CNC-ге»
  деп анық белгілеу керек; ондағы outer айналмауы DXF-пен қайшылық тудырады (review-shop-drill).
- Толық шешім: өз **Базис скриптіміз** (ресми API, MIT) — панельдерді готовый өлшеммен құрып, біздің
  `drilling.ts` тесіктерін `Mount1`/`Mount` арқылы әлем координатасына қояды (`flattenTree` позасы бар).
  Экспорт: `.js` файл (офлайн, JSON ішінде) — сервер/код қажет емес.
