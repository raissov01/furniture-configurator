# Базис нобайлары

`scripts/extractBasisThumbs.mjs` тек B3D/FR3D ішіндегі стандарт PNG chunk тізбегін кеседі. Файлдың басқа құрылымын талдамайды. Модуль WebP нобайлары 160 px, quality 75 болып `public/library/basis/` ішіне жазылады; бірдей PNG мазмұны бір файлды бөліседі. `manifest.json` ішіндегі `paths` толық архив жолын, `modules` каталогтағы бірегей `standard/<атау>` немесе `gola/<атау>` кілтін сақтайды. UI толық архив жолдарын жүктемес үшін ықшам `catalog.json` тек `modules` картасын ұстайды.

```sh
node scripts/extractBasisThumbs.mjs "$HOME/Downloads/Базис библиотеки.zip"
```

Қайта іске қосқанда мазмұны бірдей файл өзгермейді. Аралық RAR мен ашылған файлдар жүйенің уақытша қалтасына түседі және қате болса да жойылады.

Фурнитура архиві ортақ каталогқа кірмейді. Цех иесі оны жеке қалтаға ғана шығара алады:

```sh
node scripts/extractBasisThumbs.mjs "$HOME/Downloads/Базис библиотеки.zip" --hardware-private "$HOME/.cache/aismebel-basis-hardware"
```

`hardware-manifest.json` ішіндегі жол файл атауын нобаймен байланыстырады. Қажет нобайды жеке кітапхана карточкасындағы «Загрузить превью» арқылы жүктегенде, сурет тек сол аккаунттың `LibraryItem.thumbnail` өрісінде сақталады. FR3D моделі импортталмайды, сондықтан нобай өзі геометрия жасамайды.
