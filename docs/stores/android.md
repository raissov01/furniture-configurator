# Android: AisMebel өлшеу қабығы

## Қазір жиналатын өнім

`npm run cap:sync` `native/` ішіндегі ортақ `MeasurementWizard` UI-ын жергілікті веб активке жинап, `android/` жобасына көшіреді. Бұл қабық өлшем мен фотоны қолданбаның IndexedDB деректерінде сақтайды. Қолданбаны жабу және қайта ашу деректерді өшірмейді; қолданбаны жою не оның деректерін тазалау жергілікті көшірмені жояды. Бұл жинақта серверлік синхрондау, толық 3D редактор және онлайн төлем жоқ. Бұл шектеулерді listing-те де жасыруға болмайды.

Leica DISTO D5 құрылғысын Android Bluetooth баптауында пернетақта ретінде жұптап, Text Mode (m) қосады. Фокусталған өріске келген `1.234m` мәтіні бүтін мм-ге айналады, өлшем көзі мен уақыты сақталады. Бұл GATT драйвері емес; құрылғысыз тест осы мәтінді терумен өтеді. Басқа BLE құралын қолдаймыз деп жазуға болмайды.

## Жинау

1. Node 22, Android Studio және Android SDK орнатылады. `ANDROID_HOME` SDK каталогына қойылады (мысалы, `~/Android/Sdk`). `npm ci`.
2. `npm run icons:native`, содан кейін `npm run cap:sync`.
3. Пилот: `cd android && ./gradlew assembleDebug`. Дайын APK: `android/app/build/outputs/apk/debug/`.
4. Upload key сыртта жасалады және қауіпсіз сақталады. Репода `.jks`, `.keystore`, `.env` және пароль болмайды.
5. `AISMEBEL_KEYSTORE_PATH`, `AISMEBEL_KEYSTORE_PASSWORD`, `AISMEBEL_KEY_ALIAS`, `AISMEBEL_KEY_PASSWORD` CI secret не жергілікті environment арқылы беріледі. `npm run build:aab` бәрін тексеріп, `android/app/build/outputs/bundle/release/app-release.aab` шығарады.
6. AAB-ты Play Console-ға жүктегенде [Play App Signing](https://developer.android.com/studio/publish/app-signing) қосылады. Upload key backup-ы мен Play қол қойған кілт бөлек сақталады.

`kz.aismebel.app` — осы реподағы бастапқы application ID. Алғашқы Play жүктемесіне дейін иесі бірегей package name ретінде бекітуі керек; жарияланған соң өзгерту жаңа қолданба жасаумен тең. `versionCode` әр жаңа жүктемеде өседі. Құпиялылық бетінің жария URL-ы (`/privacy`) және оператордың нақты байланыс деректері толтырылмайынша store submission жасалмайды.

## Жабық тест

Жаңа жеке Play developer account үшін Google-дың [production access ережесінде](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en) кемінде 12 тестердің 14 күн үздіксіз жабық тестке тіркелуі талап етіледі. Тестке дейін account түрін Play Console-да тексеру керек.

Тест жоспары: 12 нақты Android тестерді тіркеу; APK/AAB орнату; желіні өшіру; өлшем мен фото қосу; қолданбаны толық жабу және қайта ашу; D5 Text Mode немесе мәтін эмуляторымен мән енгізу; қайта іске қосқаннан кейін дереккөз/уақыт пен фотоның сақталғанын тексеру. Әр тестердің құрылғысы, Android нұсқасы, нәтиже және ақау күні жазылады. Жойып қайта орнату жергілікті деректі жоғалтатыны алдын ала айтылады.

Google Play-дің [User Data](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en-GB) нысанын нақты шығарылған native жинақ бойынша толтыру қажет. Веб-қосымшадағы синхрондауды Android қабығында бар деп көрсетуге болмайды. Скриншоттар тек осы қолданбадан түсіріледі; PRO100/Ecru интерфейсі қолданылмайды.

## Шығаруға дейін қалған қақпалар

- Нақты оператор атауы/байланысы, сервердегі дерек сақтау мерзімі және жария `/privacy` URL.

- Жабық тест кезеңі және Google production access мақұлдауы. Осы реподағы код бұл қақпаларды автоматты өтпейді.
