# Панельдерді негізгі экранға жалғау — интеграция тізімі

**Күні:** 2026-09-20, кеш
**Кім істейді:** координатор (мен), агенттер емес

Бүгін жеті агент қатар жұмыс істеді. Әрқайсысы өз панелін **жеке**
жасады әрі өз демо бетінде көрсетті — себебі `components/Configurator.tsx`
біреу ғана өзгерте алады. Енді оларды бір жерге жинау керек.

⚠ Бұл құжат — **менің** тізімім. Агенттер бұған тимейді.

## Істелуі керек

1. **`DockHost`-ты `Configurator.tsx`-ке қосу.** Scene бекітілген
   (PRO100-дағыдай), қалғаны докингке қатысады.
2. **Мәзірден панель ашу.** «Вид» мәзіріне әр панельдің қосқышы.
   ⚠ `91e4634`-те мәзір жолағы бар, соған қосылады.
3. **Қос басу → қасиеттер.** Қазір қос басқанда деталь редакторы
   ашылады; PRO100-да қалқымалы қасиеттер терезесі. Бүгін жасалған
   бес қосымша (`Общее · Размеры · Материал · Расчёт · Производство`)
   сол терезенің ішіне көшеді — **қайта жазылмайды**.
4. **`ImportPanel`-дің `onImport` шақыруын** нағыз әрекетке қосу
   (`store/configurator.ts`). Агент оны әдейі бос қалдырды.
5. **Ескі `ModuleList`-ті шешу.** `StructurePanel` оны алмастыра ма,
   әлде екеуі де қала ма? ⚠ `ModuleList`-ке e2e сүйенеді — тексеру керек.
6. **Демо беттерін өшіру** (интеграциядан КЕЙІН):
   `/dock-demo` `/library-demo` `/panels-demo` `/replace-find-demo`
   `/dxf-import-demo`. Бәрі уақытша деп белгіленген.

## ⚠ Гочалар — бүгін нақты ұрынғандар

- **e2e ескі басқару элементтеріне сүйенеді.** `scripts/e2e.mjs`
  `h.menu('Создать', …)`, `h.menu('Проект', …)` деп дәл мәтінмен іздейді,
  `Tour.tsx` `data-tour="shop"`/`"export"`-қа сүйенеді. Макет агенті
  сондықтан ескі батырмаларды **өшірмей** қалдырды — дұрыс шешім.
  Интеграцияда да соны ұмытпау керек.
- **`Collapsible` балаларын DOM-нан алып тастамайды** — e2e соқыр болады.
- **Докинг күйі React Strict Mode-та жоғалады** — `ref` емес, `useState`
  керек (`963d1c6`-те түзетілді).

## Шешім күтетіндер

- **`Room` тек тікбұрыш.** Тікбұрыш емес DXF жоспары қоршау тікбұрышына
  дейін азаяды. Көпбұрышқа кеңейту — бөлме геометриясына тәуелді бәрін
  қозғайды. **Пайдаланушыдан сұралды, жауап жоқ.**
- **Жұмыс ақысы парақ басы ма, тесік/м² басы ма** (`CLAUDE.md §6`).
  **Пайдаланушыдан сұралды, жауап жоқ.**
