# Өз каталогының интерфейсі

`04b-own-catalog` өзегі `codex/0927-int` ішінде бар: ашық материал дерегі,
артикулдық фурнитура, Базис Excel / PRO100 INI парсері және цехқа байланған API.
Бұл жұмыс сол деректі цех қолдана алатын интерфейске жалғайды. Базис каталогы
тапсырыс берушінің келісіміне сай орнында қалады; лицензияланған кітапхананың
файлдары ортақ каталогқа қосылмайды.

## Қадамдар

- [x] Біріктіру қақтығысын шешу, `typecheck` және барлық тестті жүргізу.
- [x] Материал сүзгісін тестпен жасау: өндіруші, коллекция, декор коды; нақты
  бастапқы дерек пен өлшемді көрсету; цех профиліне таңдаған материалды қосу.
- [x] Цехтың жеке импорт UI-ы: файл, баған сәйкестігі, алдын ала көрініс пен
  жолдық қате, құқық растауы, сақтау/өшіру, квота мен шек хабарламасы. Қолдану
  үшін тек ағымдағы цехтың API жауабын алу.
- [x] Фурнитураның каталог артикулын UI-да таңдау; толық емес присадка
  сызбасын анық көрсету, ешбір белгісіз санды есепке алмау.
- [x] Жаңа UI сценарийлерін e2e-пен тексеру, build, барлық тест, typecheck,
  diff ревью; шағын коммиттер және таза жұмыс ағашы.

## Шекара

`.b3d`/`.meb`/`.sto` файлдарының жабық форматтарын парсингке қосу жоспарланбайды.
PRO100 суретін жеке жүктейтін API мен `OwnTextureMapper` бар; image API-ге
цехтық оқу рұқсаты мен 30 МБ жиынтық квота қосылды. Импорт өшірілгендегі
физикалық файл тазалау сақтау саясатына қалдырылады.
