# Цех присадкасын профильге көшіру жоспары

2026-09-24. Оқшау worktree: `codex/0924-shop-drill`. Базалық бұтақ: `dcae477`.

## Шешім

`ShopProfile.settings` генераторға `mergeSettings` арқылы жетеді, сондықтан 12 сұрақтың геометриялық параметрлерін осы қабатқа орналастырамыз. Профиль v7→v8 көшуінде ескі `settings` сақталады, жаңа параметрлер default арқылы толады. `HingeSystem` брендке тән өлшемдерге жауап береді; цехтық mount түрі мен қосымша бұранда шаблоны ғана профильде болады. Өндіруші/нақты артикул құжаты жоқ мәнді жаңа стандарт деп жарияламаймыз: бүгінгі default сақталады, UI цех шешуін көрсетеді. `outer` координатасын панельдің cut-space канондық координатасынан ажыратамыз; экспортта оператор аудару осіне сай түрленеді. Бұл өндірістік деректі жоймайды және қолмен қосылған тесіктерді де қамтиды.
