# 04d — Android қабығы, өлшеу, Kaspi және нақты парақ

## Шешімдер

- Веб редактордың «біздің» режиміне тимейміз. Телефонның бар `MeasurementWizard` компонентін native қабықта да қолданамыз.
- Leica DISTO D5 Text Mode құрылғысы ОС арқылы Bluetooth пернетақта ретінде жұптасады. Жоба жарияланған мәтін форматын ғана талдайды; құпия GATT протоколын болжамайды. Эмуляторда дәл сол мәтінді теру жолы тестіленеді.
- Kaspi Pay сатушы шотын POS ішінде қолмен жасайды. Қолданба тек нақты тиын сомасы мен сатушы берген HTTPS сілтемесін көрсетеді, төлемді автоматты растамайды.
- Native қабықта жергілікті активтер мен IndexedDB қолданылады. Next API және толық 3D редактор offline native жинаққа кірмейді; бұл шектеу дүкен құжатында анық жазылады.
