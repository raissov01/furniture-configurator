# Кезеңдік құрастырғыш жоспары

Мақсат: бес қадамдағы таңдау бір генераторлық драфттан нақты `Panel[]` жобасына өтеді. UI дайындық есебінде де өзектің өндірістік панельдерін қолданады.

## Жұмыс реті

- [x] Бастапқы typecheck күйін тіркеу; қолдағы шебер/өзек шекарасын тексеру.
- [x] TDD: кабинет пен жатын бөлме жиынын `generateFurniture` арқылы нақты шаблондардан құрау; бөлмеге сыйымдылық пен `generateCabinet` тексеруі.
- [x] Драфтты бір жерден `KitchenOptions` не `FurnitureOptions` ету; бес қадамда бірдей параметр қолдану.
- [x] Әр қадамға `Panel[]` негізіндегі 3D алдын ала көрініс пен `priceProject` сметасын қосу; қате айқын көрсетілсін.
- [x] 360 px ыңғайлы қадамдар мен қазақша/орысша мәтін; алты белсенді түр (әр түр браузерде тексерілді).
- [x] Мутация, толық тест/typecheck, build, алты түрге e2e және функция салыстыру кестесі; қазақша есеп негізгі ағашта бөлек жазылады.

Шектеу: құрылғы ойықтары, кедергілер, арнайы фурнитура және қондырма стандарттары тек нақты мақала/өлшем бар жағдайда ғана өндірістік генераторға кіреді. Қазір бар үлгілерден шыққан панельдер ғана дайын жоба болады.
