# 03b — модуль каталогын кеңейту жоспары

## Шешім шекарасы

Үш дереккөздің атау/өлшем метадеректерін ғана қолданамыз. Бұрыштық, радиусты,
сантехника ойығы, Gola, карго, сушка және техника ұясы толық өндірістік модель
болмайынша оларды жай тікбұрышты шкаф ретінде «дайын» каталогқа қоспаймыз.
Сенімді H × W × D қатары жоқ санатта бар seed өлшемін тек бастапқы мән ретінде
қолданамыз; оны стандарт деп жарияламаймыз. Екі субагент шегі себепті A және B
бөлек worktree-де, C мен UI негізгі 03b worktree-де орындалады.
