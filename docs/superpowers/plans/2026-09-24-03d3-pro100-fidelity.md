# 03d3 — PRO100 классикалық көрінісінің екінші айналымы

## Шешім

Нақты v7.08 эталонының ең ірі құрылымдық айырмасын алдымен жабамыз: құралдар
жолы белгішелерге айналады, ағаш сахнадан бөлек қалқымалы терезеге көшеді.
«Наш» режимінің DOM құрылымы мен әрекеттері сақталады. Бар әрекеттерге ғана
белгіше жалғанады. Бөлме, Properties және палитра жұмысы солардан кейін.

  құрылым терезесінің көріну шартын RED→GREEN және мутация арқылы бекіту.

  құрылым терезесін жабу, қайта ашу және сүйреп жылжыту; ескі режимге тимеу.

`NODE_OPTIONS=--max-old-space-size=2048 npm test -- --maxWorkers=3`,
`NODE_OPTIONS=--max-old-space-size=2048 npm run typecheck`, UI өзгерсе
