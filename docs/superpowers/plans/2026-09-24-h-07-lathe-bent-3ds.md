# Токарлық, иілген деталь және 3DS жоспары

2026-09-27. Бұл үш түр ағаштағы `solid` түйінінің айқын `fabrication`/`import`
дерегі болады. Тікбұрышты `Panel[]` тек тақтай кесімі үшін жалғыз дереккөз.
Арнайы детальдар сол канондық ағаштан туындайды; гильотина мен автоматты
присадкаға жіберілмейді.

- [x] `src/core/specialParts.ts`: бүтін мм профиль, иілім геометриясы,
  цех баптайтын ең аз радиус, позициялар, баға және иілім DXF.
- [x] v4 Zod схема, flatten, store әрекеттері және қасиеттер редакторы.
- [x] 3D: LatheGeometry, доғалы ExtrudeGeometry; 3DS/OBJ декоративті mesh.
- [x] 3DS импорт: шек, бірлік, материал/текстура, fixture және UI.
- [x] TDD, мутация, эталон тесті, толық тест/typecheck/build/e2e.

Развёрткада `Math.round(R·θ)` қолданылады: радиус — ортаңғы қабат радиусы,
бұрыш — радиан; дәл .5 мм жоғары дөңгелектенеді. Бұл өлшем шығарылғанда ғана
дөңгелектенеді, аралық есепте бөлшек сақталады. Ең аз радиус әр материалға
цехтың `minBendRadiusMm` параметрінен алынады; мән жоқ болса өндіріске
жіберілмейді, кездейсоқ стандарт таңдалмайды.

Бұрыш енгізілсе, `R = round(chord / (2·sin(θ/2)))` бүтін мм-ге алынады.
Осы бүтін радиус пен дәл енгізілген хорданы сақтау үшін өндірістік бұрыш
`2·asin(chord/(2·R))` болып қайта есептеледі; кестеде 0,001°-қа дейін
көрсетіледі. Пайдаланушы енгізген бұрыш пен есептік бұрыш аздап өзгеше болуы
мүмкін. Көрініс шекарасы бөлшекті толық қамту үшін жоғары бүтін мм-ге
дөңгелектенеді; ол раскрой өлшемі емес.

3DS/OBJ файлы мен бірге жүктелген PNG/JPEG/WebP текстуралары project JSON-ына
base64 ретінде кіреді. Бір mesh 2 МБ-тан, барлық актив 3 МБ-тан аспайды.
Текстураның сыртқы URL-ына сұрау жіберілмейді. Импортталған solid өндірістік
экспорттан тыс. Иілімнің DXF развёрткасы жеке файл және цех ZIP-іне бөлек
қосылады; панельдік DXF/CSV мен гильотин картасына кірмейді.
