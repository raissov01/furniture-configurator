# 05-phase5-library жоспары

PRO100 эталоны: Catalog терезесінде Furniture / Elements / Materials / Varia қосымшалары, жолдық қалта жолы және қалта нобайлары бар. Біз қолданыстағы `LibraryPanel` пішінін кеңейтеміз; түйіндердің бастапқы орны мен ішкі құрылымын JSON-да сақтаймыз. PNG репоға кірмейді.

- [x] `src/core/library.ts`: Zod v1 `LibraryItem`, материал сілтемелері, түйін ID-лерін қайта тағайындап ағашқа қою, материал қақтығысын тексеру, материалды жаппай ауыстыру; таза TS.
- [x] `tests/library.test.ts`: RED→GREEN, топ/тақта/шкаф, импорт, қақтығыс, өндіріс панелі, мутация.
- [x] LocalStorage кітапханасы: оқу/жазу/JSON экспорт-импорт, бүлінген кірісті ашық қате ету, қате туралы хабар.
- [x] SQLite аккаунт кітапханасы: тек өз пайдаланушысының GET/POST/DELETE API, схема мен маршрут тесттері.
- [x] `TreeDock` ішіндегі жеке «Библиотека» көрінісі: таңдалған түйінді сақтау, категория/іздеу/салынған нобай, қою, local/account, JSON экспорт/импорт, материал ауыстыру.
- [x] Интеграция: ағашқа қою `store` action-ы және project material catalog-қа импорт; ReplacePanel канондық ағаштағы material ID-лерді көреді.
- [x] Жаңа UI үшін e2e сценарий файлы: сақтау → категория/іздеу → қою → деталировка саны → reload. Оны интеграцияда оркестр жүргізеді.
- [x] Коммит алдында толық test/typecheck; diff review; қазақша есеп.

Шекара: өлшемдер тек бүтін мм, ақша тек тиын. Кітапхана `Panel[]` сақтамайды: әр қоюда канондық `SceneNode` арқылы өндіріс қайта есептеледі. Материал ID қақтығысы үнсіз біріктірілмейді — пайдаланушыға қате шығады.
