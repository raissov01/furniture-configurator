# 1-толқын: интеграция және тексеру жоспары

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans for orchestration; each independent implementation is delegated with superpowers:dispatching-parallel-agents. Steps use checkbox syntax.

**Goal:** Цех присадкасы, v4 құрылым ағашы және рөлдер/пікірлерді бөлек тексеріп, жарамды бөліктерін жергілікті `codex/0924`-ке біріктіру.

**Architecture:** Үш орындаушы үш оқшау worktree-де жұмыс істейді. Өзек таза TypeScript күйінде қалады; v4 ағашынан шыққан `Panel[]` өндірістің жалғыз көзі. Оркестр әр diff-ті қарайды, кезекпен merge жасайды және әр интеграцияны қайта тексереді.

**Tech Stack:** TypeScript, Zod, Zustand, Next.js, Vitest, қолданыстағы CDP e2e.

**Spec:** Пайдаланушының `.codex-runs/queue/_common.md`, `.codex-runs/queue/01-wave1.md` тапсырмалары; `docs/superpowers/specs/2026-09-20-free-form-editor-design.md`; `PHASE-2.md`.

## Шектеулер және шешім

- Сұрақ/мақұлдау күтілмейді: пайдаланушы алдын ала орындауды мақұлдаған.
- Барлық Node қадамдары `NODE_OPTIONS=--max-old-space-size=2048`; root Vitest ең көбі 3 worker, субагентте 2.
- Build/dev/e2e тек оркестрде, бір dev-сервер және бір браузер; ауыр қадам алдында `free -m`, available кемі 2500 МБ.
- Push/deploy/PR, `feat/tree-core`/`main`, еңбек ақысының моделі, жаңа ойдан шығарылған стандарттар мен бағалар өзгертілмейді.
- Жаңа UI мәтіні i18n; тегіс түс және 1px жиек; PNG/PRO100 материалдары commit болмайды.
- Үш тәуелсіз тармақ таңдалды: бірі сәтсіз болса қалған аяқталған бөліктерді бөгемейді. Ортақ `store/configurator.ts`, i18n, project/share API өзгерістері интеграцияда екі тараптың ниетін сақтап шешіледі.

2. Ағашқа көшу панель/смета/присадка/DXF-ті өзгертуі: seed және UI selector эквиваленттік тесттері.
3. Клиентке ішкі бағаның API арқылы ағуы немесе рөлді айналып өту: таза матрица және route 4xx/response-shape тесттері.
4. Цех профилінің ескі мәні немесе құжатсыз default өндірісті өзгертуі: v7 миграциясы, seed drilling эквиваленттігі, ресми дереккөз.
5. Топ/layer hide-lock, selection, undo арақатынасы: store тесттері және жаңа браузер сценарийі.
