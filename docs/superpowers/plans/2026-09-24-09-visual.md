# 09-visual жоспары

Негіз: `codex/0924` `efe2366`, 176 тест файлы / 1873 тест және typecheck жасыл.

PRO100 v7.08 `TMATERIALLIGHTPROPFRAME` материалдың жарыққа реакциясын, `TLIGHTSFORM` сахна жарығын бөлек баптайды. Қазіргі кодта `Decor.finish` дайын PBR пресеттерін береді, `Scene` жарығы бекітілген, `RenderPanel` тек камера скриншотын AI-ға жібереді. Жаңа мәндер **тек көрініске** әсер етеді; материал коды мен сыртқы `Decor.mapUrl` ережесі, өндірістік `Panel[]` өзгермейді. PNG/өндіруші текстурасы репоға кірмейді.

## 1. Материал PBR

- [x] `src/core/types.ts`, `schema.ts`, `projectV4.ts`: `Material.pbr` ерікті өрісі; roughness/metalness/reflection/opacity/normal map URL және бедер күші шектері. Бұрынғы v1–v4 файлдар өріссіз дәл ашылады; жаңа мән v4 roundtrip-та сақталады. `normalMapUrl` үшін сыртқы URL ғана, сурет файл жоқ.
- [x] `lib/materialLook.ts`, `lib/decorTexture.ts`, `components/PanelMesh.tsx`: `finish` preset + PBR override; normal texture **NoColorSpace** ([Three.js MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)); `frameloop=demand` үшін load callback; `meshPhysicalMaterial`/`meshStandardMaterial` ауысқанда React `key` арқылы қайта жасау. Өндіріс өлшемі қозғалған жоқ.
- [x] `components/RenderPanel.tsx` ішіндегі материал редакторы: жоба/цех материалының PBR параметрін өзгерту, i18n. `store.editShop` жоба материалын да синхрондайды.
- [x] RED→GREEN тесттер: ескі/жаңа жоба миграциясы, шектер, PBR preset override, texture color space және key логикасы. Маңызды тестке `cp` мутациясы.

## 2. Жоба жарықтары

- [x] `src/core/visual.ts` (таза TS), `projectV4.ts`: point/spot/sun түрлері, түс, қарқын, орын/бағыт; қатаң схема және ескі жобаға `[]` fallback. Өлшем орындары тек бүтін мм; бұрыш/қарқын өлшем емес.
- [x] `store/configurator.ts`: жарықтар snapshot/undo/redo, load/export/hydrate/reset; өзгеріс автосақталады.
- [x] `components/Scene.tsx`: жарықтарды мм→м-ге аударып салады; `useThree.invalidate()` өзгергенде кадр сұрайды. Бекітілген негізгі жарық бұрынғы әдепкі жобаға қалады.
- [x] `RenderPanel` жарық редакторы: қосу/өшіру, түр/қарқын/түс, point/spot орны және sun бағыты. Тегіс түс, 1px жиек, i18n.
- [x] RED→GREEN тесттер: схема, roundtrip, undo/export және `demand` invalidate байланысы; `cp` мутациясы.

## 3. Нақты 360° panorama

- [x] `lib/panorama.ts`: ағымдағы камера орнынан алты куб бағытын 90° perspective камерамен жеке render target-қа салу; сол 6 пиксель буферінен 2:1 equirectangular PNG. Canvas-тың бір көрінісін созуға болмайды. Renderer күйін `finally` қалпына келтіру.
- [x] `RenderPanel`-ге экспорт батырмасы және ашық қате; `Scene`-ден тірі renderer/scene/camera-ға қауіпсіз қолжетім. AI render ағыны сақталады.
- [x] RED→GREEN таза проекция тесті: алты бағыттың түсі дұрыс longitude/latitude-ке түседі, полюстер мен seam. `cp` мутациясы.
- [x] `scripts/e2e.mjs`-ке жаңа UI сценарийі: PBR сақтау, жарық қосу, reload, panorama PNG өлшемі. Агент браузерді іске қоспайды; оркестр интеграциядан кейін жасайды.
