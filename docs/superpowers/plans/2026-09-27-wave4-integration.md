# 4-толқын интеграциясы — орындау жоспары

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or execute the checked steps with TDD.

**Goal:** Дайын өндірістік импорт, шпон, Базис және баға өзектерін жұмыс кеңістігінің UI-ына жалғау; жабық BXF шекарасын сақтау.

**Architecture:** `src/core` таза TS болып қалады. UI файлды оқып, өзекке береді, тек тексерілген `BoardNode`/`SolidNode`-ты v4 ағашына жазады. Кітапхана Basis атауын генератор параметріне айналдырмас бұрын қолдау деңгейін тексереді.

**Tech Stack:** Next.js, React, Zustand, Zod, Vitest.

**Spec:** `.codex-runs/queue/04-wave4.md`, `docs/superpowers/specs/2026-09-25-{polygon-panel,veneer-matching,lathe}.md`.

## Global Constraints

- Барлық өлшем H × W × D және бүтін мм; ақша бүтін тиын.
- `Panel[]` өндірістік жалғыз ақиқат, `src/core`-та React/three жоқ.
- UI тегіс түс пен 1px жиек қолданады; жаңа мәтіндер i18n арқылы kk/ru жүреді.
- Басқа бұтаққа merge, push, deploy жоқ. Әр шағын коммит алдында толық тест пен typecheck.
- BXF ашық спецификациясыз экспортталмайды; өндіруші лицензиясы расталмаған актив көшірілмейді.

## Шешім

DXF еркін қисық панельдің өндірістік дәлдігін өзек әлі толық сақтамайды, сондықтан тікбұрыш емес DXF анық қате береді. BXF proprietary форматының жария XSD-і жоқ кезде шығару батырмасы жалған экспорт жасамайды. Basis атауындағы белгі өндірістік параметрге бірмәнді аударылмаса, модульді автоматты шкаф ретінде жасамаймыз.
