# Телефон өлшеу шебері және рөлдік «Бүгін»

Шешім: өлшеу құжаты мен фото IndexedDB-де сақталады; сервер рөлі тек экрандағы бағытты таңдайды, рұқсатты сервер тексереді. Дауыс/лазер дереккөзі қолмен енгізілген санның шығу тегін ғана белгілейді, құрылғыдан өлшеу деп көрсетілмейді. Қиғаш бөлме мен сәйкес емес қарсы қабырға генераторға жіберілмейді, бірақ өлшеу сақталады.

- [x] `components/mobile/measurementModel.ts`: бос құжат, бүтін мм енгізу, фото/кедергі өзгерту, қадам жарамдылығы.
- [x] `tests/mobileMeasurementModel.test.ts`: алдымен қызыл тест; кедергінің барлық жауабы/фотосы, бүтін мм, плитка қалыңдығы, дереккөз.
- [x] `app/mobile/page.tsx` және `components/mobile/MeasurementWizard.tsx`: рөлдік «Бүгін», бөлме → қабырғалар → кедергілер → тексеру, локал сақтау және ас үй шеберіне өту.
- [x] `lib/locales/kk.ts`: UI-дегі барлық жаңа орысша мәтіннің қазақшасы.
- [x] Мутация: маңызды тексеруді әдейі бұзып, тест құлайтынын көру, `cp` арқылы қайтару.
- [x] Тест, typecheck, жеке ревью және қазақша conventional коммит. Build/e2e-ні интеграция жасаған агент орындайды.

Қосымша: `measurementSync.ts` қайшылық/rejected/retry, `kitchenHandoff.ts` нақты бөлме мен өлшеу ID-і арқылы жоба жасау; оларды 16 мақсатты тест және 4 мутация тексереді.
