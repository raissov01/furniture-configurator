# «Тапсырыс» телефон P0 жоспары

## Негіз және шешім

`QORYTYNDY.md` §3.1–3.2, §3.4–3.5, `CLAUDE.md` және 09-25 PRO100 эталоны негіз. P0 көлемі есеп бойынша 8,5–9 инженер апта; осы кезекте тәуелсіз, аяқталған бөліктерді біріктіріп, қалғанын есепте нақты қалдырамыз. Өзек `codex/0925-par`-дан келді; оны қайта жазбаймыз. Жаңа экрандар 360 px-тен басталады, тұтас түс пен 1 px жиек және бар i18n механизмі қолданылады. Өндіріс өлшемдері H × W × D ретімен ғана беріледі.

## Тексеру тәртібі

Әр маңызды өзгерісте тестті әуелі қызылға жеткізу, іске асыру, әдейі мутация жасап тесттің құлауын көру, `cp` арқылы қайтару. Әр коммит алдында толық `npx vitest run --maxWorkers=3` және `npm run typecheck`. UI соңында `NODE_OPTIONS=--max-old-space-size=2048 npm run build -- --webpack`, бос порттағы e2e, серверді жабу. Офлайн қабылдау: өлшем/фото → бет жабу → ашу → желі → бірегей әрекет, қайшылық экранда көрінеді. Қалған функционал тек тексерілген көлеммен есептеледі.
