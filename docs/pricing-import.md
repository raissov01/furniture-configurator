# Цех прайсын импорттау: өзек шарты

`src/core/priceImport.ts` файл оқуды, баған сәйкестігін, алдын ала тексеруді және таңдалған прайсқа жазуды бөледі. UI кейін осы функцияларды файл таңдағышы, баған таңдағышы және растау кестесі арқылы шақырады.

1. `parsePriceFile(bytes, 'csv' | 'xlsx', { csvEncoding: 'utf-8' | 'windows-1251' })` тақырып пен жолдарды қайтарады. CSV-де `;`, `,`, Tab және тырнақша қолданылады. XLSX-тің бірінші парағы, shared strings, inline strings және сандық ұяшықтар оқылады. 5 МБ файл, 20 000 жол және XLSX үшін 20 МБ ашылған дерек шегі бар. Қате `ConfigValidationError` арқылы өріс атымен шығады.
2. `PriceColumnMap` жеткізушінің тақырыптарын `code`, `name`, `kind`, `brand`, `thickness`, `price`, `unit`, қажет болса `widthMm` және парақ өлшемдеріне байланыстырады. Баға мен бірлік міндетті; код немесе атау міндетті.
3. `priceTargetsFromShop(shop, codes)` тек цех профиліндегі материал, кромка және фурнитураны нысана етеді. Декор коды профиль атауынан жорамалданбайды. Өз каталогына `priceCodesFromOwnCatalog(materialMeta, edgeMeta)` қолданылады; басқа каталог пен фурнитура артикулдары `codes` аргументі арқылы беріледі.
4. `previewPriceImport` коды бойынша **нақты → тыныс белгісі/аралықтары алынған → бір таңба айырмасы бар ұқсас** сәйкестікті таңдайды. Сенімділік тиісінше `1`, `0.95`, `0.8`. Ұқсас код кемінде бес таңбалы болуы керек. Бренд, қалыңдық, кромка ені, парақ пішімі нысананы тарылтады. Бірнеше нысана не бір нысанаға бірнеше баға — `conflict`; код жоқ — `unmatched`.
5. `applyPriceImport(shop, preview, priceListId, approvedSimilarRows)` таңдалған прайсқа тек сәйкес жолдарды жазады. Ұқсас сәйкестік жол нөмірі арқылы жеке бекітіледі. Қайшылық болса жазу тоқтайды. Бұрынғы баға/қызмет мөлшерлемесі сақталады; өзгерген баға белсенді прайс snapshot-ына да жазылады.

Баға кірісі теңгемен жазылса, 0–2 ондық таңбаға дейін қабылданады; `120050 тиын` түрі де қабылданады. Нәтиже әрқашан бүтін тиын. Материал: парақ бағасы сол күйі, м² бағасы парақтың атаулы ауданына көбейтіліп **соңында бір рет** тиынға дөңгелектенеді. Дайын тақта/столешница: п.м.; кромка: п.м.; фурнитура: дана. Сәйкес келмейтін бірлік қайшылыққа түседі. Валюта айырбастау жасалмайды: кіріс теңге болуы керек.

UI кейін: файл/кодтау таңдауы, баған сәйкестігі, сәйкес/табылмаған/қайшылықты кесте, ұқсас кодты қолмен бекіту, прайс таңдау және импорт нәтижесін көрсету.
